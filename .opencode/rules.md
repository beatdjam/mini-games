# このリポジトリで OpenCode が作業するとき

OpenCode は、Claude が書いたタスク票（`.tasks/<ブランチ名>.md`）に沿って実装する役。計画・レビュー・コミット・PR は Claude が受け持つ。読むのはタスク票とコードだけ。書き方の決まりで守るものは、タスク票に書いてある。

## やること

- タスク票に書かれた変更だけを行う。票にない改善やリファクタはしない
- 読むのは票で指定されたファイルと範囲。それ以外のコードは、必要になったときだけ読む
  - README.md・STYLE.md・CLAUDE.md・SPEC.md（`games/<game-id>/SPEC.md`）は、票で指定された範囲だけを読む
- コードを書いたら `npm run format` で整える
- 終わったら票の完了条件のコマンドを流す
  - `npm test` は出力が長いので、ファイルに書いて末尾だけを見る: `npm test > "${TMPDIR:-/tmp}/test.log" 2>&1; tail -n 15 "${TMPDIR:-/tmp}/test.log"`。失敗したら `grep -n FAIL` で場所を探す
- 結果は `.tasks/<ブランチ名>.result.md` に書く（変えたファイル、完了条件それぞれの結果、決められなかったこと）

## やらないこと

- commit・push・ブランチの切り替え・PR の作成（`opencode.json` でも止めている）
- 作業ツリーにある、自分が作っていないファイルを消すこと・戻すこと（`git clean`・`git checkout -- <file>`・`git stash` を使わない）
- 仕様がはっきりしない所を推測で埋めること。そこで止めて、result に書く
- バランスの数値（敵・ボス・武器・チップの強さ、体力や被ダメージ）を票の指定から変えること
- 依存パッケージを足すこと・`package.json` を変えること（票で指定されたときだけ）
- リポジトリの外のファイルを読むこと・Web を見ること
- `.tasks/` 以外の場所にメモや一時ファイルを残すこと

## コマンドの注意

- プロセスを止めるときに、`pkill -f` や `pgrep -f` へ自分のコマンド行に含まれる文字列を渡さない（自分のシェルごと止まる）。`pgrep -f "vite --port [8]765"` のように、1文字を `[ ]` で囲むと自分には一致しない
- 開発サーバーを立てたら、終わったときに `kill` で止める。ビルドのテスト（`npm run test:build`）は 8766 番を使うので、ほかの作業と並行して流さない
