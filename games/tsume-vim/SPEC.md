# 詰めvim 仕様

Vim の操作を、ブラウザのターミナル風画面で問題形式に練習するゲーム。問題のバッファを編集し、最終状態がお題と一致すれば正解。最短手数は求めない。

## 遊び方

1. 左の問題一覧から問題を選ぶ。最初は第1章の「h で左へ」。
2. 「いま」のバッファをキーボードで編集する。NORMAL モードで始まる。
3. 文字の問題は、バッファの内容が「お題」と一致した時点で正解。移動だけの問題は、カーソルがお題の光った位置に来た時点で正解。
4. 正解すると、その操作の解説と「次の問題」が出る。「もう一度」で同じ問題をやり直せる。
5. 「ヒント」の「手順を見る」で、手本のキー列を表示する。

正解の判定は最終状態だけを見る。手本と違う手順でも、別のキーで同じ状態にすれば正解になる。打鍵数は記録するが、制限時間や最短手数の判定はない。

## 問題の構成

10章、193問。

| 章 | 内容 | 問題数 |
|----|------|--------|
| 1 | 移動（h j k l、0 $、w b e、gg G、数） | 14 |
| 2 | 入力と削除（x X、i a I A、o O、r、u） | 12 |
| 3 | オペレータ（dw de db、dd D、cw cc C、s S） | 12 |
| 4 | コピーと貼り付け（yy、dd p、y$、xp） | 8 |
| 5 | 行内の移動（f F t T、;、df dt ct） | 8 |
| 6 | もっと移動（+ - _、W B E、ge gE、{ }、%、桁指定、g_、検索、マーク、H M L） | 27 |
| 7 | ビジュアルモード（v V、d y c >） | 6 |
| 8 | 実践（J、>>、~、.、Ctrl-a/x、:s） | 14 |
| 9 | テキストオブジェクト（iw/aw、i"/a"、i(/a(、i{、vi(） | 8 |
| 10 | ドリル（生成した84問） | 84 |

各問題は次を持つ。

- `lines` / `cursor`: 開始時のバッファとカーソル
- `target`: 正解のバッファ
- `targetCursor`: 移動だけの問題で、正解のカーソル位置（省略時はカーソルを見ない）
- `solution`: 手本のキー列（テストで実際に流して正解になることを確かめる）

問題文・ヒント・解説は `src/i18n/ja.ts` の `data.levels` に問題 id で置く。バッファの中身は英語のコードと文章だけにする。

## 使えるキー

| キー | 動き |
|------|------|
| `h` `j` `k` `l` | 左・下・上・右へ1文字（行） |
| `0` `^` `$` | 行頭・最初の空白でない文字・行末 |
| `w` `b` `e` | 次の単語の先頭・前の単語の先頭・単語の末尾 |
| `W` `B` `E` | 空白区切りの単語で同じ動き |
| `gg` `G` | 先頭の行・最後の行 |
| `+` `-` `_` | 次の行・前の行・数えた行の最初の文字へ |
| `{` `}` | 前・次の空行（段落の切れ目）へ |
| `%` | 対応する括弧へ |
| `\|` | 数字を先に置くとその桁へ（1始まり） |
| `g_` | 行末の空白を飛ばして最後の文字へ |
| `ge` `gE` | 前の単語・空白区切りの前の単語の末尾へ |
| `H` `M` `L` | 画面の先頭・中央・最後の行へ。数で上・下からの行を選ぶ |
| `m` の次に `a`-`z` | マークを置く |
| バッククォート + `a`-`z` | マークの位置へ |
| `'` + `a`-`z` | マークの行の先頭へ |
| `''` | 直前のジャンプの行へ |
| バッククォート2つ | 直前のジャンプの位置へ |
| `{数}` | 動き・オペレータの回数（`3w`、`2dd`、`2d3w`） |
| `f` `F` `t` `T` `;` `,` | 行内の文字へ。`t` は手前、大文字は逆向き、`;` は繰り返し |
| `/` `?` `n` `N` | 前方・後方の文字列検索と、その繰り返し |
| `*` `#` | カーソル下の単語を前方・後方検索 |
| `i` `a` `I` `A` | カーソルの前・後ろ・行頭・行末から入力 |
| `o` `O` | 下・上に空行を作って入力 |
| `x` `X` | カーソルの文字・前の文字を削除 |
| `r` | 1文字を置換 |
| `d` `c` `y` | 削除・変更・コピー。動きと組み合わせる（`dw`、`cw`、`y$`） |
| `dd` `cc` `yy` | 行単位の削除・変更・コピー |
| `D` `C` `S` `s` `Y` | 行末までの削除・変更、行の置換、1文字の置換、行のコピー |
| `p` `P` | レジスタを後ろ・前に貼る |
| `"{a-z}` | レジスタを選ぶ。`"ayy` で a にコピー、`"ap` で貼る |
| `J` | 次の行をつなぐ |
| `~` | 大文字と小文字を入れ替える |
| `u` `Ctrl-r` | 元に戻す・やり直す |
| `i w` `a w` | 単語の中身・単語と周りの空白 |
| `i "` `a "` / `i '` `a '` | 引用符の中身・引用符ごと |
| `i (` `a (` / `i {` `a {` / `i [` `a [` / `i <` `a <` | 括弧の中身・括弧ごと |
| `.` | 直前の変更を繰り返す |
| `Ctrl-a` `Ctrl-x` | カーソル以降の数を増やす・減らす |
| `:` | 行番号へ移動、`:s/old/new/` で置換 |
| `v` `V` | 文字単位・行単位の範囲選択 |
| `>` `<` | インデント（2文字） |
| `Esc` | INSERT / VISUAL から NORMAL へ |

`cw` は Vim と同じく、単語の後ろの空白を残す（`ce` と同じ範囲）。`dw` は次の単語の先頭までを消す。`t` は単体の移動では文字の手前へ行くが、オペレータと組み合わせると手前の文字までを含める（`dt,` はカンマを残す）。

検索は正規表現ではなく、入力した文字列をそのまま探す。`/` はカーソルの次から、`?` は前から探し、端まで行くと反対側へ回り込む。`n` は直前の向き、`N` は逆の向き。

マークは `m` の次に `a`〜`z` を押して置く。`` `a `` は置いた桁まで、`'a` はその行の最初の文字へ。`''` は直前のジャンプの行へ戻る。

`.` は直前の変更のキー列を繰り返す。`3x` のような数付きの変更も、その数ごと繰り返す。`:` は行番号（`:3`）と `:s/old/new/`、`:%s/old/new/g` を扱う。置換は正規表現ではなく文字列。

## 画面

- 上段: タイトル、正解数、問題一覧とキー一覧のボタン
- 左: 章ごとの問題一覧。正解した問題には `✓` が付く
- 中央: 問題名と指示、「いま」のバッファ、「お題」のバッファ
- 下段: モード・行と桁・打鍵数・手本の打鍵数・ベスト
- ヒントと、正解時の解説
- キー一覧（ダイアログ）: このゲームで使うキーだけを載せる

行末の空白は `·` で表示する。`de` や `dw` の結果を目で確かめられるようにするため。

## 記録

- `localStorage` のキー `tsume-vim/progress` に、コースとドリルの問題 id ごとの最小打鍵数を保存する。
- `localStorage` のキー `tsume-vim/endless` に、エンドレスの自己ベストを保存する。
- 値がある問題を正解済みとして扱う。保存に失敗してもゲームは続く。
- 進み具合のリセットは画面に置かない。ブラウザのサイトデータを消すと最初に戻る。

## エンドレス

- 上部の「エンドレス」で切り替える。コースに戻るときは「コース」。
- 48種類の生成器から、シードで問題を作る。削除、変更、行操作、コピー、検索、マーク、`.`、数値、`:s`、ビジュアル、H/M/L、カウント付き操作、テキストオブジェクトを混ぜる。
- ヒントは「オペレータと単語の動き」のような弱い一言だけ。手順（キー列）は出さない。
- 正解するとクリア数が増え、「次の問題」で次のシードへ進む。自己ベストは別に保存する。
- `#endless-<数>` で同じ問題を開ける。`#endless` は毎回ランダム。

## 実装

|----------|------|
| `src/main.ts` | 入口。日本語の文言を読み、画面を起動する |
| `src/core/vim/editor.ts` | Vim の小さな実装。モード、動き、オペレータ、レジスタ、undo、ビジュアル |
| `src/core/vim/text.ts` | 位置・単語・段落・括弧・テキストオブジェクト・数値の純粋な計算 |
| `src/core/vim/types.ts` | モード・オペレータ・保留中の操作などの型 |
| `src/core/vim/registers.ts` | 無名・名前付きレジスタの保持と選択 |
| `src/core/progress.ts` | `localStorage` の読み書き |
| `src/data/levels/` | コース109問を章ごとに分けたファイル（`01-move.ts`〜`09-text-objects.ts`、`index.ts` で連結） |
| `src/core/content/generate/` | シードからドリル／エンドレスの問題を作る（`base.ts`・`builders.ts`・`index.ts`、48種類） |
| `src/core/content/drills.ts` | 生成した84問のドリル |
| `src/core/content/catalog.ts` | コースとドリルを合わせた一覧 |
| `src/data/types.ts` | 問題・文言の型 |
| `src/i18n/lang.ts` | 文言の引き当て（engine は使わない） |
| `src/i18n/ja.ts` | 画面の文言、章と問題の説明、キー一覧 |
| `src/i18n/text.ts` | 文言データを型付きで読む |
| `src/ui/terminal.ts` | 画面の状態、キー入力、判定、保存、画面遷移 |
| `src/ui/elements.ts` | ページの要素の取得 |
| `src/ui/dom.ts` | 行・文字・カーソルの DOM 部品 |
| `src/ui/keyboard.ts` | ブラウザのキーイベントから Vim のキーへの変換 |

## 制限

- Vim の全機能ではない。正規表現検索、マクロ、数字レジスタ・特別なレジスタ、ウィンドウ、`Ctrl-d/u` のスクロールは扱わない（画面が固定で、バッファ全体が見えているため）。レジスタは無名と `a`-`z` / `A`-`Z` だけ。`H` `M` `L` は画面＝バッファ全体として扱う。テキストオブジェクトは単語・引用符・括弧だけで、タグ・文・段落は扱わない。
- キーボードが必要。スマホでは物理キーボードをつなぐ。
- 文章は日本語だけ。`LANG.ja` だけを読み、言語の切り替えはない。
