# Sector Dive 仕様書

ランダム生成の区画を潜るローグライトFPS。この文書は説明書と仕様書を兼ねる。数値の正はコード側で、該当箇所を「定義場所」に書いている（書き方の決まりは STYLE.md）。

## 1. ゲームの流れ

1. 拠点で出撃地点・持ち出す武器・拠点強化を選んで潜行を始める
2. 1つの深度（DEPTH）は「区画3つ＋ボス」の4ステージ。区画は出口ゲートに入ると次へ進む
3. ボスを倒すと「前進」と「帰還」の2つのゲートが出る
   - ゲートは出てから1秒たつまでは入れない（暗く、止まって見える）。出た瞬間にプレイヤーがゲートの上にいたら、一度離れる（中心から2.2m以上）まで入れない。ボスを倒した瞬間に足元へ出たゲートで、気づく前やドロップを拾う前に飛ばされないため（`PORTAL` in src/data/level.ts）
   - 前進: 次の深度へ。チップや拾った武器は持ったまま
   - 帰還: 潜行を終えて、ビットと武器を全部持ち帰る
4. HPが0になると潜行失敗（ロスト）。持ち帰れるものが減る（→ 9.2）

区画の中身は毎回ランダム生成。深度ごとのセクター（ステージの種類）の順番も、潜行ごとにシャッフルされる。

## 2. 操作

| 操作 | スマホ | PC |
|------|--------|----|
| 移動 | 画面左をドラッグ | WASD |
| 視点 | 画面右をドラッグ（射撃ボタンを押したままドラッグでも可） | マウス（画面クリックでロック） |
| 射撃 | 右の射撃ボタン / 左の小さい射撃ボタン | 左クリック / F |
| ダッシュ | ダッシュボタン（設定でスティック倒し切りも可） | Space / Shift |
| リロード | リロードボタン（弾切れで自動） | R |
| 武器の持ち替え | 画面下の武器欄をタップ | Q / 1 / 2 / ホイール |
| 武器を拾う | 近づくと出る「持ち替え」「バッグへ」ボタン | G で持ち替え / E でバッグへ |
| 回復キット | 回復ボタン（所持数はボタンに表示） | H（所持数はHPの下に表示） |
| バッグ | 右上の BAG | Tab / I |
| 全体マップ | ミニマップをタップ | M |
| 一時停止 | 右上の II | Esc / P |

- **武器を拾う**: 「持ち替え」は2枠目が空いていればそこに入れ、埋まっていれば手に持っている武器と入れ替える（元の武器はその場に落ちる）。「バッグへ」はバッグに入れる（満杯なら入らない）
  - 拾う前に、手に持っている武器との差（火力・1発・弾倉）が ▲▼ で出る。火力はリロードと会心の平均込みで撃ち続けたときの、敵1体への毎秒ダメージの目安（チップ・拠点強化・武器のオプション込み。`weaponStats` in src/actors/weapons.ts）。バッグのカードにも火力が出て、レールガンは15m先の火力、ランチャーは爆発半径（その中の敵すべてに当たる）を横に添える（`weaponReachText` in src/screens/base.ts）
- **自動射撃**: ONだと、照準が敵に重なったとき自動で撃つ。スマホではデフォルトON。自動射撃・エイム補正・照準の赤表示は、霧で見える距離（霧が6割かかる距離、`visibleRange`）の内側の敵だけが対象。手動の射撃は距離の制限なし
- **エイム補正**: なし / 弱 / 強。強いほど、照準から少しずれた敵にも弾が寄る
- **ボタン配置の編集**: 設定か一時停止から開く。射撃・左の射撃・ダッシュ・リロード・回復をドラッグで動かし、0.7〜1.6倍に拡大縮小できる
- **全画面**: 設定・一時停止・右上ボタンで切り替え。ホーム画面に追加（PWA）すると最初から全画面・横向きで起動する

## 3. プレイヤー

| 項目 | 値 | 定義場所 |
|------|----|----------|
| 最大HP | (100 ＋ 拠点強化「装甲」15/段 ＋ 再起動ボーナス「強化外骨格」10/段) ×（1 ＋ 再起動ボーナス「耐久記録」0.05/段） | `startMaxHp` (src/core/rules.ts) |
| 被弾後の無敵 | 0.45秒 | `damagePlayer` |
| スタミナ | 最大 100 ＋「持久力」20/段。回復 34/秒 ×（1 ＋「冷却」0.12/段）。使用後0.5秒は回復しない | `newPlayer`, `update` |
| ダッシュ | スタミナ45消費。0.2秒、移動速度3.3倍、0.32秒無敵 | `update` (src/flow/update.ts) |
| 段差 | 足元より0.7以上高い床には登れない。低い所へは落ちられる | `STEP` (engine/src/world/tiles.ts) |
| 回復キット | 所持上限3。1個で HP +40、最大HPの25%のほうが多ければそちら（深くなって最大HPが増えても効くように）。開始時 1 ＋「救急箱」の段数。上限まで持っているときに拾うと、その場で使って1個分回復する（1個使ってから拾い直すのと同じ） | `useKit`, `kitHealAmount`, `KIT_MAX`, `updatePickup` |

- **被弾の向き**: 視界の外（横方向の画角の9割より外）から当たったときだけ、照準のまわりに攻撃元の方向を指す赤い弧を0.6秒出す（`hitDirection` in src/ui/hud.ts、`TUNE.hitDirTime`）。表示中は振り向きに合わせて向きを追う。正面からの被弾は画面のビネットだけ。方向は、弾なら撃った位置、近接・突進・爆発・衝撃波・ボスのビームならその発生位置。危険床と自分の爆発には出さない

## 4. 武器

### 4.1 種類（定義: `WEAPONS` in src/data/weapons.ts）

| 武器 | 威力 | 間隔(秒) | 弾倉 | リロード | 特徴 | 解放 |
|------|------|----------|------|----------|------|------|
| ハンドガン | 16 | 0.26 | 12 | 1.1 | 基準の武器 | 最初から |
| SMG | 6 | 0.062 | 45 | 1.7 | 連射と装弾数で押す。移動中もブレない | 250 |
| ショットガン | 13×8発 | 0.7 | 6 | 2.0 | 散弾。近いほど多くの粒が当たる。敵を0.8m押し返す（1発につき1回。何粒当たっても同じ） | 320 |
| レールガン | 90 | 1.1 | 4 | 2.2 | 4体まで貫通。15m以上先は威力1.5倍。ブレない。盾持ちの盾も貫く | 520 |
| ランチャー | 70 | 1.15 | 2 | 2.4 | 爆発半径5の範囲攻撃（下の補足） | 700 |

- **ランチャーの補足**
  - 爆心から40%の範囲は威力が落ちない。範囲内の敵すべてに当たり、少し（0.8m）押し返す
  - 自分が爆心近く（半径の6割以内）にいると、7 × 被ダメージの伸び（6.1章）のダメージを受ける
  - 爆炎は視界を塞がないよう、小さく短めにしている
  - 弾倉チップ（拡張弾倉）の効果は半分。貫通の効果は爆発半径 +15%（1につき）に置き換わる
  - 1回に撃つロケットは3発まで。分裂弾で増えた分のうち、超えた分は1発ごとの威力に回す（`maxShots`）
- 移動中は弾のばらつきが少し増える（SMG・レールガンを除く）
- 連射がフレームより速いとき（連射チップを重ねた SMG など）は、1フレームに複数発撃つ（1フレーム最大8発。撃っていない間の持ち越しは1フレーム分まで）。画面のフレームレートで連射速度が頭打ちにならない（`update` in src/flow/update.ts）
- 自分の弾は同時に480発まで。超えたときは、いちばん前に撃った弾を消して新しい弾を出す（新しい弾が出ずに見た目も当たりも消える、ということがない。`spawnPBullet`）
- 「解放」はビットで拠点の基本武器として解放するコスト。解放すると出撃装備に選べて、改造（9.2.1）もできる。潜行中はどの武器も拾える

### 4.2 レアリティ・+値・オプション（定義: `RARITY`, `rollWeapon`, `AFFIX`）

- **レアリティ**: ★標準 ×1.0（灰）/ ★★改良 ×1.25（青）/ ★★★試作 ×1.55（金）。拠点の基本武器も同じ表示（改造前は★標準）。拠点の武器かどうかは、バッグと出撃装備の欄に「拠点の武器（失わない）」と出る。数字は威力倍率。武器名・拾える武器の枠線・バッグと倉庫のカードの左端がこの色になる。深いほど高レアリティが出やすい（判定 = 乱数 ＋ min(進行度 × 0.025, 0.6)。1.05 を超えると★★★、0.68 を超えると★★。D5 あたりで頭打ちになり、それより深くても★★★ 約55%・★★ 約37%・★ 約8%）
- **+値**: +1ごとに威力 +8%。上限なし
  - 階層レベル = floor((進行度 − 2) × 0.6)。進行度は 6.1章を参照
  - 85%は階層レベルと同じか、0〜2低い値になる。15%は階層レベルを超え、さらに30%ずつ1段上がる判定が続く
  - D1 3/3 から出始める。ボスのドロップは進行度＋2の階層レベルで判定する
- **オプション**: D2 から1つ付くことがある。D3 以降は2つ付くことも。**その武器を手に持っている間だけ効く**

| オプション | 効果 |
|------------|------|
| 大容量弾倉 | 装弾数 +30% |
| 速射装填 | リロード −20% |
| 高速機関 | 連射速度 +10% |
| 照準補正 | 会心率 +8% |
| 吸収回路 | 撃破ごとにHP +2 |
| 軽量フレーム | 移動速度 +6% |
| 徹甲弾 | 貫通 +1 |
| 採集機構 | ビット獲得 +10% |

- ドロップする武器種の重み: ハンドガン2 / SMG3 / ショットガン3 / レールガン2 / ランチャー1（`DROP_POOL`）

## 5. チップ（潜行中の強化）

区画の敵を全滅させると 50% でチップが出る（残り50%は回復キットとビット）。ボスからも1枚出るので、1深度でおよそ8枚。選択肢のそれぞれが 12% で「レア」（金色のカード、名前に＋、効果が約1.75倍）になる。拾うと3枚（再起動ボーナスで4枚）から1枚を選ぶ。**効果はその潜行の間だけ。持ち帰れない。** 定義: `PERKS`

| チップ | 通常 | レア（＋） |
|--------|------|-----------|
| 過負荷弾 | 与ダメージ +20%（足し算） | +35% |
| 連射回路 | 連射速度 +15%（足し算） | +26% |
| 装甲パッチ | 最大HP +20、HP 20回復 | +35 |
| 修復パッチ | HPを最大値の50%回復 | 85% |
| 吸収コード | 撃破ごとにHP +3 | +5 |
| 貫通弾 | 貫通 +1（チップでは最大3。ランチャーでは爆発半径 +15%） | +2 |
| 分裂弾 | 発射数 +1。全弾当てたときの合計ダメージ +20%（1枚ごと）を弾数で分け合う。**最大7枚**（下の補足） | なし |
| 軽量化 | 移動速度 +12%（足し算） | +21% |
| 弱点解析 | 会心率 +15%（会心は2倍ダメージ、上限40%。爆発も1回ごとに会心判定する） | +26% |
| 瞬発回路 | スタミナ回復 +35%（基本値の35%を足し算） | +60% |
| 連鎖爆破 | 自分で倒した敵が周囲を爆破（Lv +1。半径 2.5＋0.5×Lv、ダメージ 18×Lv×与ダメージ倍率×敵HPの伸び（6.1章。再起動倍率は除く）。爆破で倒れた敵はさらには爆発しない） | Lv +2 |
| 磁力 | ビット回収範囲 +80%（足し算）、ビット獲得 +10% | なし |
| 高速装填 | リロード −25%（足し算、最大 −60%） | −44% |
| 拡張弾倉 | 装弾数 +40%（足し算、最大 +150%） | +70% |
| 予備タンク | 最大スタミナ +30 | +52 |

上限のあるチップ（弱点解析・高速装填・拡張弾倉・貫通弾・分裂弾）は、上限に達すると選択肢に出なくなる。

- **分裂弾の補足**
  - 例: レールガンは2本×0.6倍、ショットガンは9粒×約1.07倍
  - 1発撃ちの武器では横に扇状に広がる。0.05rad 間隔で、扇全体が 0.15rad を超える枚数からは間を詰めて幅 0.15rad に収める（`SPLIT_FAN`）
  - 最大7枚なのは、多く重ねると弾が増えるより威力の倍率として効くようになり、過負荷弾より強いダメージ強化になってしまうため（`SPLIT_MAX`）

チップ選択のカードには、そのチップに関係する今の値（例: 現在 与ダメージ +51%）が出る。選択画面の下の「現在の性能を見る」を開くと、性能一覧も見られる（普段は畳んである）。

一時停止画面とバッグ画面の「現在の性能」に、拠点強化・チップ・手持ち武器を全部足した値が出る。与ダメージは手持ち武器のレアリティと+値込み、装弾数は手持ち武器に実際に入る数（ランチャーは弾倉チップが半分）で出す。取得チップは結果画面と同じく種類ごとの枚数でまとめる（`statsHTML` in src/screens/pause.ts）。

## 6. ステージ

### 6.1 難易度（定義: `difficultyAt`, `bossDifficulty`, `spawnEnemy`）

- **進行度**: 強さの計算に使う値。深度の入口が「深度 × 5」、ボスが「深度 × 5 ＋ 4」で、その間の区画は等間隔に割り振る（D1 1/3 = 0、D1 2/3 = 1.33、D1 3/3 = 2.67、D1 BOSS = 4、D2 1/3 = 5 …）。1深度の区画数を変えても、深度ごとの強さの伸びが変わらないようにするための値（`progressOf` in src/core/rules.ts）
- 敵HP倍率 = 1.4 × 伸び(進行度 ÷ 5, 1.55, 1.22) × 再起動倍率（深度1つごとの伸びが、D3 の入口までは1.55倍、そこから D12 の入口にかけて少しずつ下がり、その先は1.22倍。`DEPTH_HP_GROWTH` / `DEPTH_HP_LATE`、1.4 は `ENEMY_TUNE.hpMul`）
- ボスHP倍率 = 1.33 × 1.3 × 伸び((進行度 − 4) ÷ 5, 1.85, 1.24) × 再起動倍率（D1 ボスで約1.73、D2 で約3.2、D3 で約5.9。深度1つごとの伸びが、D3 ボスまでは1.85倍、そこから D12 ボスにかけて少しずつ下がり、その先は1.24倍。`BOSS_TUNE`）
- 伸び(x, 前半, 後半): 深度1つあたりの倍率が、x = 2 までは「前半」、x = 2〜11 で「前半」から「後半」へ（対数で直線的に）下がり、x = 11 から先は「後半」。その倍率を x まで積み重ねた値（`hpGrowth` in src/data/progress.ts。2 と 11 は `GROWTH_SLIDE`）
- **設計の考え方**
  - 潜行中の伸び（チップ・拾う武器）を気持ちよく感じられるようにしつつ、深度ごとに「入った直後は少しきつく、チップが揃うと楽になり、ボスで締まる」波を作る
  - 雑魚の伸び（1.55倍）はプレイヤーの伸びとほぼ同じにしてある。ボスは雑魚より一段早く伸ばして、ビルドを試す壁にする。目安は D3 ボスで強いビルド20〜30秒、ふつうのビルド1分前後
  - チップも武器の＋値も足し算で伸びるので、深くなるとプレイヤーの伸びは深度1つあたり1.3倍前後まで落ちる。敵もボスもそれに合わせて伸びを少しずつ緩め、深いボスでも60〜90秒、長くても5分ほどで倒せるようにしてある（同じ伸びのままだと D14 のボスに10分以上かかっていた）
  - 緩め方を途中で一気に切り替えると、切り替えた直後の深度がその手前より楽になるので、なだらかに下げている
  - 試算（深い潜行のビルドの配分で、分裂弾は7枚まで、倒すまでの時間）: D3 ボス 約1分 → D6 約70秒 → D10 約85秒 → D14 約95秒 → D20 約2分半 → D25 約4分
- 被ダメージの伸び = (1 ＋ 0.045 × 進行度) × 再起動倍率（`damageScaleAt` in src/core/stages.ts）。敵・ボスの攻撃、危険床、自分のロケットの自爆がこの割合で強くなる
- 敵の攻撃力 = 基本値 × 1.25 × 被ダメージの伸び（1.25 は `ENEMY_TUNE.dmgMul`）。ボスは 10 × 被ダメージの伸びを基準に、攻撃ごとの倍率を掛ける
- 敵の射撃間隔 = 敵ごとの基本値 × 0.85（`ENEMY_TUNE.fireInterval`）
- 再起動倍率 = 1 ＋ 0.15 × min(再起動回数, 7)（最大 ×2.05。`REBOOT_DIFF_CAP`、`rebootMulOf` in src/core/rules.ts）
- 1部屋の敵数 = min(11, 部屋の広さ÷3（九龍城は÷4、最低2）, 2〜4 ＋ floor(進行度 × 0.3))。スタート部屋には敵がいない
- 深い深度ほど、そのセクターの敵のうち厄介な種類（狙撃手・盾持ち・ブルート・ボマー・スプリッター・タレット）が出やすい。深度1つごとに +10%、最大50%（`ENEMY_TUNE.elitePerDepth` / `ELITE_TYPES`）

### 6.2 地形

- タイル1辺4m。床の高さは 0（地面）/ 1.2（瓦礫＝遮蔽物）/ 2（高台・高架通路）
- **高台**: 大きい部屋の内側に作られる。スロープ1本で上がれる。部屋の外周は地面のままなので、出入口は必ずつながる
- **高架通路**: 両側が壁の直線通路（長さ5タイル以上）が、スロープ付きの高い通路になる
- **瓦礫**: 高さ1.2で登れない。弾は上を通る。敵の視線も高さで遮られる
- **危険床**: 武器・敵・チップは危険床の上には出ない。スタート部屋（出入口のマスも含む）には置かない。1.4秒オン → 1.6秒オフの周期で、区画はオフから始まる（最初に光るまで約1.6秒）。オンになる直前0.5秒は点滅する。オン中に踏むと 7 × 被ダメージの伸び（6.1章）のダメージ（被弾後の無敵で約0.45秒ごと）
- **段差の当たり判定**: 移動の可否は進む向きの先端だけで判定する（段から降りた直後に後ろ側がかかっていても、離れる方向には動ける）。降りたあとに段と重なっていたら押し出す
- 生成後の検証: 開始部屋から全部屋へ行けて、戻れることを開発用チェック（11章）で確認している

## 9. 拠点と持ち帰り

拠点画面は、上に所持ビットなどの記録、その下に4つのタブ、画面下に DIVE の帯（中断データがあるときは再開と破棄）。最後に開いたタブはブラウザに覚えておく（`localStorage` の `sd-base-tab`）。

| タブ | 中身 |
|---|---|
| 出撃 | 出撃地点、出撃装備、基本武器、倉庫 |
| 強化 | 拠点強化、再起動 |
| 練習 | ボス練習 |
| 設定 | 設定、ゲーム一覧・更新履歴・プライバシーポリシーへのリンク、データの完全消去 |

背の低い画面（高さ 520px 以下、スマホの横向き）では、説明文を隠して上部を詰め、DIVE を1行にする。

### 9.1 ビット

| 入手元 | 量 | 定義場所 |
|--------|----|----------|
| 敵 | 敵ごとの基本値 × 0.6 × (1 ＋ 0.05 × 進行度) | `killEnemy` |
| 区画制圧（チップが出なかった場合） | 6 ＋ 進行度 | `roomCleared` |
| ボス | 45 × ボスHP倍率 | `bossDown` |

獲得量には「回収効率」「磁力」「採集機構」の補正が掛かる。回復キットは敵から6%で落ちる。

### 9.2 帰還・ロスト（定義: `endRun` in src/flow/run.ts）

| | 帰還 | 死亡 / 放棄 |
|--|------|-------------|
| ビット | 全部 | 半分 |
| 装備中の武器 | 次の出撃装備になる | 失う（基本武器は失わない） |
| バッグの武器 | 倉庫へ | 失う |
| ショートカット | そのまま | 1段階閉じる |

- **出撃装備**: 2枠。基本武器（解放済みなら何度でも使える）か倉庫の武器を割り当てる。倉庫の武器は出撃した時点で拠点から出ていく（死ぬと戻らない）
- **倉庫**: 12本まで。あふれた分は安いものから自動で売却
- **売値** = 8 ＋ 解放コスト × 0.06 ＋ レアリティ加算（0 / 20 / 55）＋ +値 × 10 ＋ オプション数 × 20
- **武器カードの数字**: 拠点の基本武器・倉庫のカードには「出撃時の火力」と、1発・連射・弾倉を出す。出撃した直後の値（拠点強化・再起動ボーナス・武器のオプション込み、チップ無し）で、持ち込む武器を比べるためのもの。レールガン・ランチャーの添え書きはバッグと同じ（`weaponStatText` in src/screens/base.ts）
- **結果画面のチップ**: その潜行で取ったチップを、多い順に「分裂弾×25、過負荷弾×16（うちレア3）…」とまとめて出す（同数なら先に取った順。レアは同じチップに合算し、1枚だけのものはそのままの名前。`chipSummary` in src/core/rules.ts）。取った順の一覧は「取得順を見る」を開くと出る（深く潜ると100枚近くになるため、普段は畳む）

### 9.2.1 基本武器の改造

拠点の「基本武器」で、解放済みの武器の+値とレアリティをビットで上げられる。基本武器は持ち出しても死んでも失わないので、改造も失わない。

- +値: +1ごとに費用 50 × 1.5^(今の+値)（+1 が 50、+5 が 253、+10 が 1,922）。+10 を超えると、1段ごとに1.2倍（+11 が 2,883、+15 が 5,979、+21 が 17,849。+10 → +21 の合計は約9万）（`modPlusCost`）
- 上限 = max(+10, 開通した最深の深度 × 1.5)（`modPlusCap` in src/core/rules.ts、`MOD_PLUS_MAX`・`MOD_CAP_PER_DEPTH`）。例: DEPTH 14 まで開通していれば +21
  - 「開通した最深の深度」は再起動してからいちばん深く開通したショートカット（`save.peak`）。死んでショートカットが閉じても下がらない。再起動で戻る
  - ねらい: 深い深度で死んで拾った武器を失っても、拠点の武器で1〜2深度戻れば立て直せるようにする。同じ深度からすぐ再挑戦できるほどにはしない（拾う武器は深度ごとに約+3なので、拠点の武器は少し弱い）
  - 拠点の「基本武器」の欄に今の上限を表示する
- レアリティ: ★★改良へ 300、★★★試作へ 900（`MOD_RARITY_COST`）
- 改造は武器の種類ごと。出撃装備に割り当てると、潜行開始時点の改造状態で持ち出す（`basicNow`）
- 再起動すると改造もリセットされる

### 9.3 ショートカット

- 深度Nのボスを倒すと DEPTH N+1 から出撃できるようになる。死ぬと1段階閉じる
- 途中の深度から出撃すると、飛ばした深度の数だけ「ショートカット補給」のチップを選べる。補給は1回で同じチップを5枚ぶん得る（`TUNE.supplyTimes`。上限のあるチップは上限で止まる）
  - 修復パッチは出撃直後にはHPが満タンで無駄になるので、補給の候補には出さない（`noSupply`）
  - 5枚ぶんにしている理由: 歩いて潜ると1深度でおよそ8枚取れるので、1回1枚では深い深度からの出撃が成り立たなかった（D14 から出撃で13枚だと、火力は歩いてきた場合の1/40ほど）。5枚ぶんで約6割の枚数になり、飛ばした深度の武器やビットがない分だけ少し不利、くらいに収まる
- **難しさの目安**: 出撃地点のボタンに、今の出撃装備と拠点強化で見た目安を5段階で出す（楽勝 / 余裕 / 適正 / 厳しい / 無謀。`readiness` in src/core/rules.ts）
  - 火力 = 出撃装備でいちばん強い武器のチップなしの毎秒ダメージ（改造・オプション込み）÷ 無改造ハンドガン × 与ダメージ倍率（拠点の「出力」と再起動ボーナス「戦闘記録」。`startDmgMul`）× 補給の効き e^(0.6 × 飛ばす深度数^0.69)（種類の違うチップは掛け算で効くが、同じ種類は足し算なので、重ねるほど1回あたりの効きは下がる。深い潜行のチップ構成に合わせた式。`supplyGain`、`TUNE.supplyCurve`）÷ その深度の敵HPの伸び（6.1章の伸び × 再起動倍率）÷ (その深度のボスHPの伸び ÷ 敵HPの伸び)^0.75（途中から出撃したときの最初の壁はその深度のボスなので、ボスの硬さを4分の3だけ加味する。`READY_BOSS_WEIGHT`）
  - 耐久 = 最大HP（拠点強化・再起動ボーナス込み。`startMaxHp`）÷ 100 ÷ その深度の敵の攻撃力の伸び（(1 ＋ 0.045 × 5 × 深度) × 再起動倍率）
  - 目安の値 = √(火力 × 耐久)。1.0 が「DEPTH 1 から、無改造ハンドガンで拠点強化なし」。1.5 以上で楽勝、1.15 以上で余裕、0.85 以上で適正、0.6 以上で厳しい、それ未満で無謀（`READY_CUTS`）
  - 例: 何も強化していないと DEPTH 1〜2 適正、DEPTH 3 厳しい、DEPTH 5 は無謀。拠点の強化を上限・再起動3回でショットガン +37★★★ なら DEPTH 7 まで楽勝、DEPTH 14 で適正、DEPTH 20 で厳しい。出力・装甲を上限にしてレールガン +10★★★ なら DEPTH 3 で楽勝

### 9.4 中断とチェックポイント

- 区画やボス部屋に入るたびに、その時点の状態（HP、チップの効果、武器、バッグ、ビット、ルート）をチェックポイントとして保存する。出撃直後の持ち込みチップは、選び終わった時点で保存し直す
- 一時停止の「中断して拠点へ」を選ぶか、スマホで裏に回したアプリが終了されるなどでページが閉じると、次に開いたとき拠点に RESUME が出る。**その区画の開始時点の状態で**最初から再開する（地形は作り直される。区画の途中で拾ったビットやチップは戻る）
- 死亡・放棄・帰還で潜行が終わると、チェックポイントは消える
- 中断中は新しい潜行を始められない。破棄すると死亡と同じ扱い
- ボス練習はチェックポイントを作らない

### 9.6 ボス練習

拠点の「ボス練習」から、6体のボスのどれか1体とだけ戦える（最初から全ボスを選べる。まだ出会っていないボスは「未遭遇」と表示）。

- 強さは D1 / D2 / D3 / D5 のボス相当から選ぶ。今の出撃装備を使う（チップはなし）が、倉庫の武器を持ち出していても失わない
- 倒すと「拠点へ」のゲートだけが出る。ビット・武器・チップの報酬、ショートカット、撃破数、再起動の解放などには一切影響しない
- 練習で戦っても「遭遇済み」にはならない（遭遇済みは本編でボスが出たときだけ付く）
- 中断はできない（一時停止から放棄はできる）

### 9.7 セーブの書き出し・読み込み

設定タブの「データ」欄から、セーブを別の端末やブラウザへ移せる（`exportSave` / `importSave` in src/core/save.ts）。

- **書き出す**: 今のセーブ（中断中の潜行・設定・ボタン配置を含む全部）を1行のコードにして表示する。「コピー」と「ファイルに保存」（`sector-dive-save-日付.txt`）ができる
- **読み込む**: コードを貼り付けるか、保存したファイルを選ぶ →「読み込む」で中身を確かめる →「上書きして読み込む」で確定。今のセーブは上書きされる。読み込んだあとはページを読み込み直して、全部の画面に反映する
- 読み込んだセーブは、起動時に読むのと同じ扱い（足りない項目は既定値で補い、古い形式は変換する）
- コードは `SD1:` で始まる。暗号化ではなく、ぱっと見で中身が読めず、手で書き換えると読み込めなくなる程度（形式は engine/SPEC.md「セーブ」）。別のゲームのコード、書き換えたコード、途中で切れたコードは「読み込めなかった」と出す

### 9.8 データの完全消去

拠点の「データ」欄から実行する。赤い警告ダイアログで消えるものを確認してから消去する。セーブデータ（設定とボタン配置を含む）が全部初期状態に戻る。

### 9.9 再起動（プレステージ）

- DEPTH 3 以降のボスを倒すと解放される
- 実行すると、拠点強化・武器の解放・倉庫・ショートカット・ビットがリセットされる。再起動ポイントを 2 ＋ max(0, 開通済みショートカット − 3) 得る
- 敵は再起動1回ごとに +15% 強くなる。7回（+105%）で頭打ち。永続ボーナスは数回の再起動で取り切れるので、上限が無いと再起動直後の DEPTH 1 から進めなくなるため
- 実行前の確認に、再起動後の敵の強さと、再起動直後（無改造ハンドガン・拠点強化なし）の DEPTH 1 の難しさの目安（9.3）を出す
- 中断中の潜行があるときは実行できない

| 永続ボーナス | 効果/段 | 最大段 | 費用 |
|--------------|---------|--------|------|
| 採掘効率 | ビット獲得 +10% | 5 | 1pt |
| 強化外骨格 | 最大HP +10 | 5 | 1pt |
| 初期資金 | 再起動直後のビット +150 | 3 | 1pt |
| 遺物 | 再起動直後、倉庫に試作武器1本 | 2 | 2pt |
| 選択肢拡張 | チップの候補が4枚 | 1 | 3pt |
| 戦闘記録 | 与ダメージ +5%（拠点の「出力」と足し算） | なし | 1pt ＋ 今の段数（1, 2, 3, …） |
| 耐久記録 | 最大HP +5%（拠点強化・強化外骨格込みの値に掛ける） | なし | 1pt ＋ 今の段数 |

- 戦闘記録・耐久記録は上限がなく、段が上がるほど費用が1ptずつ上がる（`REBOOT_ENDLESS`、`rebootCost` in src/core/rules.ts）。ほかの永続ボーナスを取り切ったあとも、再起動するたびに少しずつ強くなれるようにするため。敵の強化は7回で頭打ちなので、それ以降は再起動するほど得になる。出撃地点の難しさの目安にも入る
- 画面では、上限のあるボーナスは段数ぶんの目盛り、上限のないものは「Lv 段数」で表示する

  | 廃墟街 | 72 | 風の音と、長い残響を引く寂しい単音 |
  | 九龍城 | 100 | 暗いネオン。低い音域のシンセと、ゆっくりした4つ打ち |
  | 旧市街ビル群 | 76 | ノワール寄り。物悲しい鍵盤と歩くようなベース |

- 4つの層（パッド・アルペジオ・ベース・ドラム）を状況で重ね分ける（`LAYER_MIX`）。探索中はパッドとアルペジオ中心、起きた敵が30m以内にいると戦闘の重ね方になってベースとドラムに加え「緊張の層」（16分で刻む低音の脈動と4小節かけて開くフィルター、細かいハイハット、2小節に1回の半音でぶつかる不協和音）が入る
- どの曲も短調かそれより暗い音階で、明るく聞こえる和音を避け、低めの音域と暗めの音色にしてある
- ボス戦は、そのセクターの曲のアレンジ（`bossArrangement`）。調とコード進行はそのまま、テンポ1.3倍、低い持続音を足して、16分のアルペジオ、オクターブで動くベース、16分のハイハット、小節頭のコードの刻み
- 一時停止中は BGM が小さくなる
- 効果音も合成（`SFX` in src/data/sfx.ts）。銃声は「鋭いアタック・胴鳴り・低音の衝撃・余韻」の4層を重ね、1発ごとに音程を少し揺らす。ハンドガンは高く短い胴鳴りと軽い低音で、乾いた切れのいい音。ショットガンは撃った後にポンプ音、レールガンは電気の音から低いうなり、ランチャーは噴射音。効果音の出口には軽いコンプレッサーをかけている
- 設定に「BGM」「効果音」の音量スライダーがある。ブラウザの仕様で、最初に画面を触るまでは音が出ない

### 10.2 結果のシェア

- 帰還・死亡・放棄の結果画面に、目立たないリンク「結果をシェア」を出す。ボス練習では出さない
- 画像: 1200×630 の結果カード。結果（再起動済みなら右上に「REBOOT ×回数」）、到達区画とセクター、撃破数、倒したボス、構えていた武器（レアリティの色）、チップ（多い順に4つ、同じものは「×枚数」）
- 投稿文: `SECTOR/DIVE <到達区画> <セクター>から帰還した。<ボス>を撃破。#SectorDive` とゲームの URL。ボスが2体以上なら `ボス<数>体を撃破（監視体×3・圧壊機…）` のように種類ごとに数えてまとめる（`bossSummary`。深く潜ると X の文字数上限を超えていたため）。結果カードのボス欄も同じまとめ方
- タッチ端末で画像付きの共有ができるときは共有シートを開く
- PC では共有シートを使わない（Mac などの共有シートには X が出ない）。結果画面の中に、カードの画像と「画像をコピー」「画像を保存」「X で投稿」（投稿文入りの投稿画面）を出す。1回のクリックでコピーとタブを開くのを両方やると、コピーが失敗するので分けている
- 「画像をコピー」はクリップボードに画像を書けないブラウザでは出さない
- 倒したボスは `run.bosses` に記録し、中断データにも含める

### 10.3 感想フォーム

- 全ゲーム共通の Google フォームを開く（仕組みは engine/SPEC.md「感想フォーム」）。フォームが設定されていない間は導線を出さない
- 導線は2か所: 結果画面（帰還・死亡・放棄・ボス練習の後）の目立たないリンク「感想・不具合を送る」と、拠点画面の設定タブの「リンク」欄
- 「プレイ情報」欄に入れる内容（言語によらず読めるよう ID で書く。`src/ui/feedback.ts`）
  - 結果画面から: 結果（練習ならボスと勝敗）、到達区画、撃破数、手持ちとバッグの武器（`shotgun+37 r2 [mag,speed]` の形。r はレアリティ 0〜2）、チップ（多い順、`splitx25`、レアは `+`）、倒したボス
  - 拠点画面から: 出撃装備、最高到達区画
  - どちらにも: 再起動回数、ショートカットの深度、出撃回数、表示言語、タッチ操作かどうか

## 11. 技術メモ

- 構成: `index.html`（HTML・CSS）＋ 入口の `src/main.ts` ＋ `src/` 以下のモジュール。`src/main.ts` が全部を読み込んだあと、言語・音量・拠点画面・システムの登録とループの開始（`boot`）を行う（決まりは engine/SPEC.md の「基本」）
- 多言語化: 文言は `src/i18n/`（`ja` と `en`）。武器・チップ・セクターなどの名前と説明は `src/i18n/text.ts` が定義に流し込む。言語は設定タブで切り替え、`save.settings.lang` に保存する。英語のときは本文のフォントを Chakra Petch にする
- 確認用に `?lang=en` を付けると英語で開く
- 潜行中に一時停止画面で言語を切り替えると、「現在の性能」・左上の区画名・ボス名も書き直す（`refreshRunText` in src/screens/pause.ts）
