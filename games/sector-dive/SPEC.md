# Sector Dive 仕様書

ランダム生成の区画を潜るローグライトFPS。この文書は説明書と仕様書を兼ねる。
**コードの数値を変えたら、この文書も同じコミットで更新すること。** 数値の正はコード側で、該当箇所を「定義場所」に書いている。

## 1. ゲームの流れ

1. 拠点で出撃地点・持ち出す武器・拠点強化を選んで潜行を始める
2. 1つの深度（DEPTH）は「区画3つ＋ボス」の4ステージ。区画は出口ゲートに入ると次へ進む
3. ボスを倒すと「前進」と「帰還」の2つのゲートが出る
   - 前進: 次の深度へ。チップや拾った武器は持ったまま
   - 帰還: 潜行を終えて、ビットと武器を全部持ち帰る
4. HPが0になると潜行失敗（ロスト）。持ち帰れるものが減る（→ 7章）

区画の中身は毎回ランダム生成。深度ごとのセクター（ステージの種類）の順番も、潜行ごとにシャッフルされる。

## 2. 操作

| 操作 | スマホ | PC |
|------|--------|----|
| 移動 | 画面左をドラッグ | WASD |
| 視点 | 画面右をドラッグ（射撃ボタンを押したままドラッグでも可） | マウス（画面クリックでロック） |
| 射撃 | 右の射撃ボタン / 左の小さい射撃ボタン | 左クリック / F |
| ダッシュ | ダッシュボタン（設定でスティック倒し切りも可） | Space / Shift |
| リロード | リロードボタン（弾切れで自動） | R |
| 武器の持ち替え | 画面下の武器欄をタップ | Q / 1 / 2 / ホイール |
| 武器を拾う | 近づくと出る「拾う」ボタン | E |
| 回復キット | 回復ボタン | H |
| バッグ | 右上の BAG | Tab / I |
| 全体マップ | ミニマップをタップ | M |
| 一時停止 | 右上の II | Esc / P |

- **自動射撃**: ONだと、照準が敵に重なったとき自動で撃つ。スマホではデフォルトON
- **エイム補正**: なし / 弱 / 強。強いほど、照準から少しずれた敵にも弾が寄る
- **ボタン配置の編集**: 設定か一時停止から開く。射撃・左の射撃・ダッシュ・リロード・回復をドラッグで動かし、0.7〜1.6倍に拡大縮小できる
- **全画面**: 設定・一時停止・右上ボタンで切り替え。ホーム画面に追加（PWA）すると最初から全画面・横向きで起動する

## 4. 武器

### 4.1 種類（定義: `WEAPONS` in js/core.js）

| 武器 | 威力 | 間隔(秒) | 弾倉 | リロード | 特徴 | 解放 |
|------|------|----------|------|----------|------|------|
| ハンドガン | 16 | 0.26 | 12 | 1.1 | 基準の武器 | 最初から |
| SMG | 6 | 0.062 | 45 | 1.7 | 連射と装弾数で押す。移動中もブレない | 250 |
| ショットガン | 11×8発 | 0.7 | 6 | 2.0 | 5m以内は威力1.8倍。1発で同じ敵に7発以上当てると追加ダメージ（近距離倍率込み1発分の3倍）。敵を押し返す | 320 |
| レールガン | 90 | 1.1 | 4 | 2.2 | 4体まで貫通。15m以上先は威力1.5倍。ブレない。盾持ちの盾も貫く | 520 |
| ランチャー | 52 | 1.15 | 2 | 2.9 | 爆発半径5。爆心から40%の範囲は威力が落ちない。敵を吹き飛ばす。自分が爆心近くにいると14ダメージ | 700 |

- 移動中は弾のばらつきが少し増える（SMG・レールガンを除く）
- 「解放」はビットで拠点の基本武器として解放するコスト。潜行中はどの武器も拾える

### 4.2 レアリティ・+値・オプション（定義: `RARITY`, `rollWeapon`, `AFFIX`）

- **レアリティ**: ★標準 ×1.0（灰）/ ★★改良 ×1.25（青）/ ★★★試作 ×1.55（金）。数字は威力倍率。武器名・拾える武器の枠線・バッグと倉庫のカードの左端がこの色になる。深いほど高レアリティが出やすい
- **+値**: +1ごとに威力 +8%。上限なし
  - 階層レベル = floor((進行度 − 2) × 0.6)。進行度は 6.1章を参照
  - 85%は階層レベルと同じか、0〜2低い値になる。15%は階層レベルを超え、さらに30%ずつ1段上がる判定が続く
  - D1 3/3 から出始める。ボスのドロップは進行度＋2の階層レベルで判定する
- **オプション**: D2 から1つ付くことがある。D3 以降は2つ付くことも。**その武器を手に持っている間だけ効く**

| オプション | 効果 |
|------------|------|
| 大容量弾倉 | 装弾数 +30% |
| 速射装填 | リロード −20% |
| 高速機関 | 連射速度 +10% |
| 照準補正 | 会心率 +8% |
| 吸収回路 | 撃破ごとにHP +2 |
| 軽量フレーム | 移動速度 +6% |
| 徹甲弾 | 貫通 +1 |
| 採集機構 | ビット獲得 +10% |

- ドロップする武器種の重み: ハンドガン2 / SMG3 / ショットガン3 / レールガン2 / ランチャー1（`DROP_POOL`）

## 5. チップ（潜行中の強化）

区画の敵を全滅させると 70% でチップが出る（残り30%は回復キットとビット）。拾うと3枚（再起動ボーナスで4枚）から1枚を選ぶ。**効果はその潜行の間だけ。持ち帰れない。** 定義: `PERKS`

| チップ | 効果 |
|--------|------|
| 過負荷弾 | 与ダメージ +20% |
| 連射回路 | 連射速度 +15% |
| 装甲パッチ | 最大HP +20、HP 20回復 |
| 修復パッチ | HPを最大値の50%回復 |
| 吸収コード | 撃破ごとにHP +3 |
| 貫通弾 | 貫通 +1 |
| 分裂弾 | 発射数 +1（1発の威力 −20%） |
| 軽量化 | 移動速度 +12% |
| 弱点解析 | 会心率 +15%（会心は2倍ダメージ） |
| 瞬発回路 | スタミナ回復 +35% |
| 連鎖爆破 | 撃破した敵が周囲を爆破 |
| 磁力 | ビット回収範囲 +80%、ビット獲得 +10% |
| 高速装填 | リロード −30% |
| 拡張弾倉 | 装弾数 +50% |
| 予備タンク | 最大スタミナ +30 |

一時停止画面とバッグ画面の「現在の性能」に、拠点強化・チップ・手持ち武器を全部足した値が出る。

## 6. ステージ

### 6.1 難易度（定義: `diffOf`, `bossDiff`, `spawnEnemy`）

- **進行度**: 強さの計算に使う値。深度の入口が「深度 × 5」、ボスが「深度 × 5 ＋ 4」で、その間の区画は等間隔に割り振る（D1 1/3 = 0、D1 2/3 = 1.33、D1 3/3 = 2.67、D1 BOSS = 4、D2 1/3 = 5 …）。1深度の区画数を変えても、深度ごとの強さの伸びが変わらないようにするための値（`prog` in js/core.js）
- 敵HP倍率 = (1 ＋ 0.1 × 進行度 ＋ 0.5 × floor(深度 / 3)) × 再起動倍率
- ボスHP倍率 = (1 ＋ 0.08 × 進行度 ＋ 0.5 × floor(深度 / 3)) × 再起動倍率
- 敵の攻撃力 = 基本値 × (1 ＋ 0.045 × 進行度) × 再起動倍率
- 再起動倍率 = 1 ＋ 0.15 × 再起動回数
- 1部屋の敵数 = min(9, 部屋の広さ÷3（九龍城は÷4、最低2）, 2〜4 ＋ floor(進行度 × 0.3))。スタート部屋には敵がいない

### 6.2 地形

- タイル1辺4m。床の高さは 0（地面）/ 1.2（瓦礫＝遮蔽物）/ 2（高台・高架通路）
- **高台**: 大きい部屋の内側に作られる。スロープ1本で上がれる。部屋の外周は地面のままなので、出入口は必ずつながる
- **高架通路**: 両側が壁の直線通路（長さ5タイル以上）が、スロープ付きの高い通路になる
- **瓦礫**: 高さ1.2で登れない。弾は上を通る。敵の視線も高さで遮られる
- **危険床**: 1.4秒オン → 1.6秒オフの周期。オンになる直前0.5秒は点滅する。オン中に踏むと7ダメージ（被弾後の無敵で約0.45秒ごと）
- **段差の当たり判定**: 移動の可否は進む向きの先端だけで判定する（段から降りた直後に後ろ側がかかっていても、離れる方向には動ける）。降りたあとに段と重なっていたら押し出す
- 生成後の検証: 開始部屋から全部屋へ行けて、戻れることを開発用チェック（10章）で確認している

## 7. 敵（定義: `ENEMY` in js/core.js）

| 敵 | HP | 行動 |
|----|----|------|
| クローラー | 30 | 高速で近づいて殴る |
| ドローン | 24 | 浮遊。距離9を保って撃つ |
| タレット | 60 | 動かない。3方向に撃つ |
| ブルート | 150 | 遅い。殴りと5方向射撃 |
| 狙撃手 | 40 | 距離18を保つ。1.1秒レーザーで狙い（最後の0.25秒は固定）、高速弾を1発撃つ |
| 盾持ち | 90 | 正面からの弾を防ぐ。向き直りは毎秒約90度と遅いので回り込める。盾は耐久90（深度で増える）で、正面から撃ち続けると壊れて1秒よろける。耐久が半分を切ると盾の色が変わる。爆発とレールガンは盾を無視する |

## 8. ボス（定義: js/bosses.js）

アリーナは12×12タイル。ボスHPの基本値に 6.1章のボスHP倍率が掛かる。HPが半分を切ると行動が激しくなる。

| ボス | HP基本値 | 行動 | 攻略の目安 |
|------|----------|------|------------|
| 監視体 WATCHER | 1300 | 弾の輪・扇状射撃・螺旋弾。半分でドローン3体 | 輪の隙間を抜けるか、ダッシュの無敵で抜ける |
| 圧壊機 CRUSHER | 1800 | 突進、跳躍して衝撃波、追尾弾 | 衝撃波はダッシュで抜ける。壁か柱に突っ込ませると1.6秒スタンし、被ダメージ1.5倍 |
| 深層核 NOISE CORE | 2400 | 回転レーザー（2本、半分以下で3本）、弾の輪、雑魚召喚 | レーザーはダッシュの無敵で越える |
| 狙撃体 PHANTOM | 1100 | 柱の近くへワープ（プレイヤーに近い2か所以外から選ぶ）→ 2.2秒（半分以下で1.6秒）待機 → 1.3秒レーザーで狙い → 高速弾（2.4倍ダメージ）。半分以下で2連射。3回に1回ドローン2体（場に2体まで） | 柱の陰に隠れる。点滅したらダッシュ |
| 三連体 TRINITY | 1700 | 3体が中心を周回し、体力を共有。順番に扇状射撃、定期的に弾の輪。半分以下で1体ずつ突進 | どれを撃っても削れる |
| 要塞核 BASTION | 1500 | シールド中は無敵。周囲の砲台（HP140）4基を全部壊すと12秒だけ無防備になり、その間は被ダメージ1.5倍。時間切れで砲台を2基（半分以下で3基）再建 | 砲台を素早く壊して、開いた間に本体へ集中 |

ボスを倒すと、ビット、チップ1枚、回復キット1個、武器1本（改良以上）が出る。

## 9. 拠点と持ち帰り

### 9.1 ビット

| 入手元 | 量 | 定義場所 |
|--------|----|----------|
| 敵 | 敵ごとの基本値 × 0.6 × (1 ＋ 0.05 × 進行度) | `killEnemy` |
| 区画制圧（チップが出なかった場合） | 6 ＋ 進行度 | `roomCleared` |
| ボス | 45 × ボスHP倍率 | `bossDown` |

獲得量には「回収効率」「磁力」「採集機構」の補正が掛かる。回復キットは敵から6%で落ちる。

### 9.2 帰還・ロスト（定義: `endRun` in js/game.js）

| | 帰還 | 死亡 / 放棄 |
|--|------|-------------|
| ビット | 全部 | 半分 |
| 装備中の武器 | 次の出撃装備になる | 失う（基本武器は失わない） |
| バッグの武器 | 倉庫へ | 失う |
| ショートカット | そのまま | 1段階閉じる |

- **倉庫**: 12本まで。あふれた分は安いものから自動で売却
- **売値** = 8 ＋ 解放コスト × 0.06 ＋ レアリティ加算（0 / 20 / 55）＋ +値 × 10 ＋ オプション数 × 20
- **出撃装備**: 2枠。基本武器（解放済みなら何度でも使える）か倉庫の武器を割り当てる。倉庫の武器は出撃した時点で拠点から出ていく（死ぬと戻らない）

### 9.3 ショートカット

- 深度Nのボスを倒すと DEPTH N+1 から出撃できるようになる。死ぬと1段階閉じる
- 途中の深度から出撃すると、飛ばした深度の数だけ「ショートカット補給」のチップを選べる

### 9.4 中断

- 一時停止の「中断して拠点へ」で、その時点の状態（HP、チップの効果、武器、バッグ、ビット、ルート）を保存する
- 拠点の RESUME で、**中断した区画を最初から**再開する（地形は作り直される）
- 中断中は新しい潜行を始められない。破棄すると死亡と同じ扱い

### 9.5 拠点強化（定義: `UPGRADES`）

| 強化 | 効果/段 | 最大段 | 費用（l = 現在の段数） |
|------|---------|--------|------------------------|
| 装甲 | 最大HP +15 | 6 | 80 × 1.6^l |
| 出力 | 与ダメージ +8% | 6 | 100 × 1.6^l |
| 駆動系 | 移動速度 +5% | 4 | 90 × 1.7^l |
| 冷却 | スタミナ回復 +12% | 4 | 90 × 1.7^l |
| 持久力 | 最大スタミナ +20 | 4 | 90 × 1.7^l |
| 回収効率 | ビット獲得 +15% | 5 | 150 × 1.7^l |
| 救急箱 | 開始時の回復キット +1 | 2 | 220 × 2^l |
| 持ち込みチップ | 開始時にチップを1枚選ぶ | 2 | 450 × 2.2^l |

### 9.6 ボス練習

拠点の「ボス練習」から、6体のボスのどれか1体とだけ戦える（最初から全ボスを選べる。まだ出会っていないボスは「未遭遇」と表示）。

- 強さは DEPTH 1 のボス相当。今の出撃装備を使うが、倉庫の武器を持ち出していても失わない
- 倒すと「拠点へ」のゲートだけが出る。ビット・武器・チップの報酬、ショートカット、撃破数、再起動の解放などには一切影響しない
- 練習で戦っても「遭遇済み」にはならない（遭遇済みは本編でボスが出たときだけ付く）
- 中断はできない（一時停止から放棄はできる）

### 9.7 データの完全消去

拠点の「データ」欄から実行する。赤い警告ダイアログで消えるものを確認してから消去する。セーブデータ（設定とボタン配置を含む）が全部初期状態に戻る。

### 9.8 再起動（プレステージ）

- DEPTH 3 以降のボスを倒すと解放される
- 実行すると、拠点強化・武器の解放・倉庫・ショートカット・ビットがリセットされる。再起動ポイントを 2 ＋ max(0, 開通済みショートカット − 3) 得る
- 敵は再起動1回ごとに +15% 強くなる
- 中断中の潜行があるときは実行できない

| 永続ボーナス | 効果/段 | 最大段 | 費用 |
|--------------|---------|--------|------|
| 採掘効率 | ビット獲得 +10% | 5 | 1pt |
| 強化外骨格 | 最大HP +10 | 5 | 1pt |
| 初期資金 | 再起動直後のビット +150 | 3 | 1pt |
| 遺物 | 再起動直後、倉庫に試作武器1本 | 2 | 2pt |
| 選択肢拡張 | チップの候補が4枚 | 1 | 3pt |

## 10. 技術メモ

- 構成: `index.html`（HTML・CSS）＋ `js/` 以下のクラシックスクリプト。全ファイルが1つのグローバルスコープを共有するので、**読み込み時に実行されるコードは、自分より後のファイルの関数を呼べない**（実行時の呼び出しは問題ない）。読み込み順は `index.html` の末尾

| ファイル | 中身 |
|----------|------|
| `js/core.js` | 共通関数、ゲームデータ（`TUNE`・武器・チップ・セクター・敵・ボス一覧など）、セーブ、効果音 |
| `js/render.js` | three.js の準備、共有ジオメトリとテクスチャ |
| `js/level.js` | 地形の生成と描画、高さ・当たり判定・視線・経路（flow field）、危険床、ゲート |
| `js/entities.js` | 弾・パーティクル・拾い物の生成、敵の生成（敵オブジェクトの項目一覧もここ） |
| `js/player.js` | プレイヤー、武器のレアリティ・+値・オプション、構えている銃のモデル、射撃、被弾、撃破 |
| `js/bosses/common.js` | ボスの共通処理（生成、体力倍率、撃破後の処理）、予告レーザー |
| `js/bosses/<名前>.js` | ボス1体ずつの生成と行動 |
| `js/input.js` | タッチ・マウス・キーボード入力、持ち替え・拾う・回復 |
| `js/hud.js` | HUD、ミニマップ、全画面、設定、ボタン配置の編集 |
| `js/game.js` | 潜行の流れ、チップ選択、一時停止、バッグ、中断、帰還・ロスト、ボス練習、拠点画面 |
| `js/enemies.js` | 敵の毎フレームの行動 |
| `js/bullets.js` | 弾の毎フレームの処理（当たり判定、盾、ショットガンの全弾ボーナスなど） |
| `js/update.js` | 毎フレームの処理（移動・カメラ・射撃・拾い物）とメインループ |
| `js/dev.js` | 開発用フック（`#smoke` など） |

- プレイヤー側の調整値（HP、スタミナ、ダッシュ、回復キット、チップ率、死亡時のビット）は `js/core.js` の `TUNE` にまとめてある
- キャッシュ対策: `index.html` のスクリプトは `js/xxx.js?v=YYYYMMDDHHMM` で読み込む。**js を変えたら v の値を全部更新する**（GitHub Pages は js を約10分キャッシュするので、古い js と新しい html が混ざると動かなくなる）。更新コマンドの例: `sed -i '' -E "s#(src=\"js/[a-z/]+\.js)\?v=[0-9]+#\1?v=$(date +%Y%m%d%H%M)#" index.html`
- 描画: three.js r128（cdnjs）。3Dモデルや画像は使わず、図形とCanvasで作ったテクスチャだけで描く
- セーブ: localStorage の `sector-dive-v1`。古いセーブも読めるように、`loadSave` で足りない項目を補っている。1深度が4区画だった頃のセーブ（`stageV` なし）は、最深記録と中断データのステージ番号を3区画の数え方に変換する
- 開発用フック（URLの末尾に付ける）
  - `#smoke`: 全セクターの区画と全ボスを一通り動かす。あわせて、段差から降りたときの詰まり、進行度、盾、ボス練習（セーブが変わらないこと）、中断→再開→破棄、データ消去を確かめ、各セクター25回ずつ生成して全部屋に行き来できるかを調べる。結果はコンソールに `SMOKE ...` で出る
  - `#view-KWLN` など: そのセクターの区画にすぐ入る（スクリーンショット確認用）
  - `#boss-phantom` など: そのボスの練習にすぐ入る（ボス名は watcher / crusher / core / phantom / trinity / bastion）
