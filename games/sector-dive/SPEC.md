# Sector Dive 仕様書

ランダム生成の区画を潜るローグライトFPS。この文書は説明書と仕様書を兼ねる。
**コードの数値を変えたら、この文書も同じコミットで更新すること。** 数値の正はコード側で、該当箇所を「定義場所」に書いている。

## 1. ゲームの流れ

1. 拠点で出撃地点・持ち出す武器・拠点強化を選んで潜行を始める
2. 1つの深度（DEPTH）は「区画3つ＋ボス」の4ステージ。区画は出口ゲートに入ると次へ進む
3. ボスを倒すと「前進」と「帰還」の2つのゲートが出る
   - 前進: 次の深度へ。チップや拾った武器は持ったまま
   - 帰還: 潜行を終えて、ビットと武器を全部持ち帰る
4. HPが0になると潜行失敗（ロスト）。持ち帰れるものが減る（→ 7章）

区画の中身は毎回ランダム生成。深度ごとのセクター（ステージの種類）の順番も、潜行ごとにシャッフルされる。

## 2. 操作

| 操作 | スマホ | PC |
|------|--------|----|
| 移動 | 画面左をドラッグ | WASD |
| 視点 | 画面右をドラッグ（射撃ボタンを押したままドラッグでも可） | マウス（画面クリックでロック） |
| 射撃 | 右の射撃ボタン / 左の小さい射撃ボタン | 左クリック / F |
| ダッシュ | ダッシュボタン（設定でスティック倒し切りも可） | Space / Shift |
| リロード | リロードボタン（弾切れで自動） | R |
| 武器の持ち替え | 画面下の武器欄をタップ | Q / 1 / 2 / ホイール |
| 武器を拾う | 近づくと出る「持ち替え」「バッグへ」ボタン | G で持ち替え / E でバッグへ |
| 回復キット | 回復ボタン（所持数はボタンに表示） | H（所持数はHPの下に表示） |
| バッグ | 右上の BAG | Tab / I |
| 全体マップ | ミニマップをタップ | M |
| 一時停止 | 右上の II | Esc / P |

- **武器を拾う**: 「持ち替え」は2枠目が空いていればそこに入れ、埋まっていれば手に持っている武器と入れ替える（元の武器はその場に落ちる）。「バッグへ」はバッグに入れる（満杯なら入らない）
  - 拾う前に、手に持っている武器との差（火力・1発・弾倉）が ▲▼ で出る。火力はリロードと会心の平均込みで撃ち続けたときの毎秒ダメージの目安（チップ・拠点強化・武器のオプション込み。レールガンの距離ボーナスと爆発は含まない。`weaponStats` in js/actors/player.ts）。バッグのカードにも火力が出る
- **自動射撃**: ONだと、照準が敵に重なったとき自動で撃つ。スマホではデフォルトON。自動射撃・エイム補正・照準の赤表示は、霧で見える距離（霧が6割かかる距離、`visibleRange`）の内側の敵だけが対象。手動の射撃は距離の制限なし
- **エイム補正**: なし / 弱 / 強。強いほど、照準から少しずれた敵にも弾が寄る
- **ボタン配置の編集**: 設定か一時停止から開く。射撃・左の射撃・ダッシュ・リロード・回復をドラッグで動かし、0.7〜1.6倍に拡大縮小できる
- **全画面**: 設定・一時停止・右上ボタンで切り替え。ホーム画面に追加（PWA）すると最初から全画面・横向きで起動する

- 「解放」はビットで拠点の基本武器として解放するコスト。解放すると出撃装備に選べて、改造（9.2.1）もできる。潜行中はどの武器も拾える

### 4.2 レアリティ・+値・オプション（定義: `RARITY`, `rollWeapon`, `AFFIX`）

- **レアリティ**: ★標準 ×1.0（灰）/ ★★改良 ×1.25（青）/ ★★★試作 ×1.55（金）。拠点の基本武器も同じ表示（改造前は★標準）。拠点の武器かどうかは、バッグと出撃装備の欄に「拠点の武器（失わない）」と出る。数字は威力倍率。武器名・拾える武器の枠線・バッグと倉庫のカードの左端がこの色になる。深いほど高レアリティが出やすい
- **+値**: +1ごとに威力 +8%。上限なし
  - 階層レベル = floor((進行度 − 2) × 0.6)。進行度は 6.1章を参照
  - 85%は階層レベルと同じか、0〜2低い値になる。15%は階層レベルを超え、さらに30%ずつ1段上がる判定が続く
  - D1 3/3 から出始める。ボスのドロップは進行度＋2の階層レベルで判定する
- **オプション**: D2 から1つ付くことがある。D3 以降は2つ付くことも。**その武器を手に持っている間だけ効く**

| オプション | 効果 |
|------------|------|
| 大容量弾倉 | 装弾数 +30% |
| 速射装填 | リロード −20% |
| 高速機関 | 連射速度 +10% |
| 照準補正 | 会心率 +8% |
| 吸収回路 | 撃破ごとにHP +2 |
| 軽量フレーム | 移動速度 +6% |
| 徹甲弾 | 貫通 +1 |
| 採集機構 | ビット獲得 +10% |

- ドロップする武器種の重み: ハンドガン2 / SMG3 / ショットガン3 / レールガン2 / ランチャー1（`DROP_POOL`）

## 5. チップ（潜行中の強化）

区画の敵を全滅させると 50% でチップが出る（残り50%は回復キットとビット）。ボスからも1枚出るので、1深度でおよそ8枚。選択肢のそれぞれが 12% で「レア」（金色のカード、名前に＋、効果が約1.75倍）になる。拾うと3枚（再起動ボーナスで4枚）から1枚を選ぶ。**効果はその潜行の間だけ。持ち帰れない。** 定義: `PERKS`

| チップ | 通常 | レア（＋） |
|--------|------|-----------|
| 過負荷弾 | 与ダメージ +20%（足し算） | +35% |
| 連射回路 | 連射速度 +15%（足し算） | +26% |
| 装甲パッチ | 最大HP +20、HP 20回復 | +35 |
| 修復パッチ | HPを最大値の50%回復 | 85% |
| 吸収コード | 撃破ごとにHP +3 | +5 |
| 貫通弾 | 貫通 +1（チップでは最大3。ランチャーでは爆発半径 +15%） | +2 |
| 分裂弾 | 発射数 +1。全弾当てたときの合計ダメージ +20%（1枚ごと）を弾数で分け合う。例: レールガンは2本×0.6倍、ショットガンは9粒×約1.07倍 | なし |
| 軽量化 | 移動速度 +12%（足し算） | +21% |
| 弱点解析 | 会心率 +15%（会心は2倍ダメージ、上限40%。爆発も1回ごとに会心判定する） | +26% |
| 瞬発回路 | スタミナ回復 +35% | +60% |
| 連鎖爆破 | 自分で倒した敵が周囲を爆破（Lv +1。半径 2.5＋0.5×Lv、ダメージ 18×Lv×与ダメージ倍率×1.55^深度（敵の体力と同じ伸び）。爆破で倒れた敵はさらには爆発しない） | Lv +2 |
| 磁力 | ビット回収範囲 +80%、ビット獲得 +10% | なし |
| 高速装填 | リロード −25%（足し算、最大 −60%） | −44% |
| 拡張弾倉 | 装弾数 +40%（足し算、最大 +150%） | +70% |
| 予備タンク | 最大スタミナ +30 | +52 |

上限のあるチップ（弱点解析・高速装填・拡張弾倉・貫通弾）は、上限に達すると選択肢に出なくなる。

チップ選択のカードには、そのチップに関係する今の値（例: 現在 与ダメージ +51%）が出る。選択画面の下の「現在の性能を見る」を開くと、性能一覧も見られる（普段は畳んである）。

一時停止画面とバッグ画面の「現在の性能」に、拠点強化・チップ・手持ち武器を全部足した値が出る。

## 6. ステージ

### 6.1 難易度（定義: `diffOf`, `bossDiff`, `spawnEnemy`）

- **進行度**: 強さの計算に使う値。深度の入口が「深度 × 5」、ボスが「深度 × 5 ＋ 4」で、その間の区画は等間隔に割り振る（D1 1/3 = 0、D1 2/3 = 1.33、D1 3/3 = 2.67、D1 BOSS = 4、D2 1/3 = 5 …）。1深度の区画数を変えても、深度ごとの強さの伸びが変わらないようにするための値（`prog` in js/system/rules.ts）
- 敵HP倍率 = 1.4 × 1.55 ^ (進行度 ÷ 5) × 再起動倍率（深度1つごとに1.55倍。`DEPTH_HP_GROWTH`、1.4 は `ENEMY_TUNE.hpMul`）
- ボスHP倍率 = 1.33 × 1.3 × 1.85 ^ ((進行度 − 4) ÷ 5) × 再起動倍率（D1 ボスで約1.73、D2 で約3.2、D3 で約5.9。`BOSS_TUNE`）
- 設計の考え方: 潜行中の伸び（チップ・拾う武器）を気持ちよく感じられるようにしつつ、深度ごとに「入った直後は少しきつく、チップが揃うと楽になり、ボスで締まる」波を作る。雑魚の伸び（1.55倍）はプレイヤーの伸びとほぼ同じくらいにしてある。ボスは雑魚より一段早く伸ばして、ビルドを試す壁にする。目安は D3 ボスで強いビルド20〜30秒、ふつうのビルド1分前後
- 敵の攻撃力 = 基本値 × 1.25 × (1 ＋ 0.045 × 進行度) × 再起動倍率（1.25 は `ENEMY_TUNE.dmgMul`。ボスは別計算）
- 敵の射撃間隔 = 敵ごとの基本値 × 0.85（`ENEMY_TUNE.fireInterval`）
- 再起動倍率 = 1 ＋ 0.15 × 再起動回数
- 1部屋の敵数 = min(11, 部屋の広さ÷3（九龍城は÷4、最低2）, 2〜4 ＋ floor(進行度 × 0.3))。スタート部屋には敵がいない
- 深い深度ほど、そのセクターの敵のうち厄介な種類（狙撃手・盾持ち・ブルート・ボマー・スプリッター・タレット）が出やすい。深度1つごとに +10%、最大50%（`ENEMY_TUNE.elitePerDepth` / `ELITE_TYPES`）

### 6.2 地形

- タイル1辺4m。床の高さは 0（地面）/ 1.2（瓦礫＝遮蔽物）/ 2（高台・高架通路）
- **高台**: 大きい部屋の内側に作られる。スロープ1本で上がれる。部屋の外周は地面のままなので、出入口は必ずつながる
- **高架通路**: 両側が壁の直線通路（長さ5タイル以上）が、スロープ付きの高い通路になる
- **瓦礫**: 高さ1.2で登れない。弾は上を通る。敵の視線も高さで遮られる
- **危険床**: 武器・敵・チップは危険床の上には出ない。1.4秒オン → 1.6秒オフの周期。オンになる直前0.5秒は点滅する。オン中に踏むと7ダメージ（被弾後の無敵で約0.45秒ごと）
- **段差の当たり判定**: 移動の可否は進む向きの先端だけで判定する（段から降りた直後に後ろ側がかかっていても、離れる方向には動ける）。降りたあとに段と重なっていたら押し出す
- 生成後の検証: 開始部屋から全部屋へ行けて、戻れることを開発用チェック（10章）で確認している

## 8. ボス（定義: js/actors/bosses.ts）

アリーナは12×12タイル。ボスHPの基本値に 6.1章のボスHP倍率が掛かる。

- **登場**: 2秒かけて現れる（その間は無敵で攻撃もしない）。ボス名が大きく出る（`BOSS_TUNE.introTime`）
- **第二段階**: HPが半分を切った瞬間に1.2秒だけ無敵になり、衝撃と「第二段階」の表示が出る。飛んでいる敵弾は消える。ここから各ボスの行動が激しくなる（`BOSS_TUNE.phaseTime`）
- 戦闘時間の目安: D1 ボスは道中のチップ込みで45〜60秒、D3 ボスは強いビルドで30秒前後、ふつうのビルドで1分強

| ボス | HP基本値 | 行動 | 攻略の目安 |
|------|----------|------|------------|
| 監視体 WATCHER | 1300 | 弾の輪・扇状射撃・螺旋弾。体力75%でドローン2体、40%でさらに3体 | 輪の隙間を抜けるか、ダッシュの無敵で抜ける |
| 圧壊機 CRUSHER | 1800 | 突進、跳躍して衝撃波、追尾弾 | 衝撃波はダッシュで抜ける。壁か柱に突っ込ませると1.6秒スタンし、被ダメージ1.5倍 |
| 深層核 NOISE CORE | 2400 | 回転レーザー（2本、半分以下で3本）、弾の輪、雑魚召喚 | レーザーはダッシュの無敵で越える |
| 狙撃体 PHANTOM | 1100 | 柱の近くへワープ（プレイヤーに近い2か所以外から選ぶ）→ 2.2秒（半分以下で1.6秒）待機 → 1.3秒レーザーで狙い → 高速弾（2.4倍ダメージ）。半分以下で2連射。3回に1回ドローン2体（場に2体まで） | 柱の陰に隠れる。点滅したらダッシュ |
| 三連体 TRINITY | 1700 | 3体が中心を周回し、体力を共有。順番に扇状射撃、定期的に弾の輪。半分以下で1体ずつ突進 | どれを撃っても削れる |
| 要塞核 BASTION | 1500 | シールド中は無敵。周囲の砲台（HP140）4基を全部壊すと12秒だけ無防備になり、その間は被ダメージ1.5倍。時間切れで砲台を2基（半分以下で3基）再建 | 砲台を素早く壊して、開いた間に本体へ集中 |

ボスを倒すと、ビット、チップ1枚、回復キット1個、武器1本（改良以上）が出る。

## 9. 拠点と持ち帰り

拠点画面は、上に所持ビットなどの記録、その下に4つのタブ、画面下に DIVE の帯（中断データがあるときは再開と破棄）。最後に開いたタブはブラウザに覚えておく（`localStorage` の `sd-base-tab`）。

| タブ | 中身 |
|---|---|
| 出撃 | 出撃地点、出撃装備、基本武器、倉庫 |
| 強化 | 拠点強化、再起動 |
| 練習 | ボス練習 |
| 設定 | 設定、ゲーム一覧と更新履歴へのリンク、データの完全消去 |

背の低い画面（高さ 520px 以下、スマホの横向き）では、説明文を隠して上部を詰め、DIVE を1行にする。

### 9.1 ビット

| 入手元 | 量 | 定義場所 |
|--------|----|----------|
| 敵 | 敵ごとの基本値 × 0.6 × (1 ＋ 0.05 × 進行度) | `killEnemy` |
| 区画制圧（チップが出なかった場合） | 6 ＋ 進行度 | `roomCleared` |
| ボス | 45 × ボスHP倍率 | `bossDown` |

獲得量には「回収効率」「磁力」「採集機構」の補正が掛かる。回復キットは敵から6%で落ちる。

### 9.2 帰還・ロスト（定義: `endRun` in js/flow/game.ts）

| | 帰還 | 死亡 / 放棄 |
|--|------|-------------|
| ビット | 全部 | 半分 |
| 装備中の武器 | 次の出撃装備になる | 失う（基本武器は失わない） |
| バッグの武器 | 倉庫へ | 失う |
| ショートカット | そのまま | 1段階閉じる |

- **倉庫**: 12本まで。あふれた分は安いものから自動で売却
- **売値** = 8 ＋ 解放コスト × 0.06 ＋ レアリティ加算（0 / 20 / 55）＋ +値 × 10 ＋ オプション数 × 20
- **出撃装備**: 2枠。基本武器（解放済みなら何度でも使える）か倉庫の武器を割り当てる。倉庫の武器は出撃した時点で拠点から出ていく（死ぬと戻らない）

### 9.2.1 基本武器の改造

拠点の「基本武器」で、解放済みの武器の+値とレアリティをビットで上げられる。基本武器は持ち出しても死んでも失わないので、改造も失わない。

- +値: +1ごとに費用 50 × 1.5^(今の+値)（+1 が 50、+5 が 253、+10 が 1,922）。上限 +10（`MOD_PLUS_MAX`）
- レアリティ: ★★改良へ 300、★★★試作へ 900（`MOD_RARITY_COST`）
- 改造は武器の種類ごと。出撃装備に割り当てると、潜行開始時点の改造状態で持ち出す（`basicNow`）
- 再起動すると改造もリセットされる

### 9.3 ショートカット

- 深度Nのボスを倒すと DEPTH N+1 から出撃できるようになる。死ぬと1段階閉じる
- 途中の深度から出撃すると、飛ばした深度の数だけ「ショートカット補給」のチップを選べる

### 9.4 中断とチェックポイント

- 区画やボス部屋に入るたびに、その時点の状態（HP、チップの効果、武器、バッグ、ビット、ルート）をチェックポイントとして保存する。出撃直後の持ち込みチップは、選び終わった時点で保存し直す
- 一時停止の「中断して拠点へ」を選ぶか、スマホで裏に回したアプリが終了されるなどでページが閉じると、次に開いたとき拠点に RESUME が出る。**その区画の開始時点の状態で**最初から再開する（地形は作り直される。区画の途中で拾ったビットやチップは戻る）
- 死亡・放棄・帰還で潜行が終わると、チェックポイントは消える
- 中断中は新しい潜行を始められない。破棄すると死亡と同じ扱い
- ボス練習はチェックポイントを作らない

### 9.5 拠点強化（定義: `UPGRADES`）

| 強化 | 効果/段 | 最大段 | 費用（l = 現在の段数） |
|------|---------|--------|------------------------|
| 装甲 | 最大HP +15 | 6 | 80 × 1.6^l |
| 出力 | 与ダメージ +8% | 6 | 100 × 1.6^l |
| 駆動系 | 移動速度 +5% | 4 | 90 × 1.7^l |
| 冷却 | スタミナ回復 +12% | 4 | 90 × 1.7^l |
| 持久力 | 最大スタミナ +20 | 4 | 90 × 1.7^l |
| 回収効率 | ビット獲得 +15% | 5 | 150 × 1.7^l |
| 救急箱 | 開始時の回復キット +1 | 2 | 220 × 2^l |
| 持ち込みチップ | 開始時にチップを1枚選ぶ | 2 | 450 × 2.2^l |

### 9.6 ボス練習

拠点の「ボス練習」から、6体のボスのどれか1体とだけ戦える（最初から全ボスを選べる。まだ出会っていないボスは「未遭遇」と表示）。

- 強さは D1 / D2 / D3 / D5 のボス相当から選ぶ。今の出撃装備を使う（チップはなし）が、倉庫の武器を持ち出していても失わない
- 倒すと「拠点へ」のゲートだけが出る。ビット・武器・チップの報酬、ショートカット、撃破数、再起動の解放などには一切影響しない
- 練習で戦っても「遭遇済み」にはならない（遭遇済みは本編でボスが出たときだけ付く）
- 中断はできない（一時停止から放棄はできる）

### 9.7 データの完全消去

拠点の「データ」欄から実行する。赤い警告ダイアログで消えるものを確認してから消去する。セーブデータ（設定とボタン配置を含む）が全部初期状態に戻る。

### 9.8 再起動（プレステージ）

- DEPTH 3 以降のボスを倒すと解放される
- 実行すると、拠点強化・武器の解放・倉庫・ショートカット・ビットがリセットされる。再起動ポイントを 2 ＋ max(0, 開通済みショートカット − 3) 得る
- 敵は再起動1回ごとに +15% 強くなる
- 中断中の潜行があるときは実行できない

| 永続ボーナス | 効果/段 | 最大段 | 費用 |
|--------------|---------|--------|------|
| 採掘効率 | ビット獲得 +10% | 5 | 1pt |
| 強化外骨格 | 最大HP +10 | 5 | 1pt |
| 初期資金 | 再起動直後のビット +150 | 3 | 1pt |
| 遺物 | 再起動直後、倉庫に試作武器1本 | 2 | 2pt |
| 選択肢拡張 | チップの候補が4枚 | 1 | 3pt |

## 9.9 BGM と効果音

BGM は音楽ファイルを使わず、Web Audio でその場で合成する（`js/flow/music.ts`）。

- セクターごとに調・音階・コード進行・テンポ・パターンが違う（`MUSIC_STYLES`）

  | セクター | テンポ | 雰囲気 |
  |----------|--------|--------|
  | 拠点 | 60 | 低いドローンと風の音の、暗いアンビエント |
  | 廃棄データ層 | 92 | 冷たくまばらなアルペジオが残響とともに鳴る。遅い鼓動のようなキック |
  | 溶融炉区画 | 80 | 重い持続低音と、工場の金属音。フリジアンの重い往復 |
  | 深層ノイズ | 66 | メロディはほぼなし。ドローン、うねるノイズ、グリッチ |
  | 廃墟街 | 72 | 風の音と、長い残響を引く寂しい単音 |
  | 九龍城 | 100 | 暗いネオン。低い音域のシンセと、ゆっくりした4つ打ち |
  | 旧市街ビル群 | 76 | ノワール寄り。物悲しい鍵盤と歩くようなベース |

- 4つの層（パッド・アルペジオ・ベース・ドラム）を状況で重ね分ける（`LAYER_MIX`）。探索中はパッドとアルペジオ中心、起きた敵が30m以内にいると戦闘の重ね方になってベースとドラムに加え「緊張の層」（16分で刻む低音の脈動と4小節かけて開くフィルター、細かいハイハット、2小節に1回の半音でぶつかる不協和音）が入る
- どの曲も短調かそれより暗い音階で、明るく聞こえる和音を避け、低めの音域と暗めの音色にしてある
- ボス戦は、そのセクターの曲のアレンジ（`bossArrangement`）。調とコード進行はそのまま、テンポ1.3倍、低い持続音を足して、16分のアルペジオ、オクターブで動くベース、16分のハイハット、小節頭のコードの刻み
- 一時停止中は BGM が小さくなる
- 効果音も合成（`SFX` in js/data/sfx.ts）。銃声は「鋭いアタック・胴鳴り・低音の衝撃・余韻」の4層を重ね、1発ごとに音程を少し揺らす。ハンドガンは高く短い胴鳴りと軽い低音で、乾いた切れのいい音。ショットガンは撃った後にポンプ音、レールガンは電気の音から低いうなり、ランチャーは噴射音。効果音の出口には軽いコンプレッサーをかけている
- 設定に「BGM」「効果音」の音量スライダーがある。ブラウザの仕様で、最初に画面を触るまでは音が出ない

### 9.10 結果のシェア

- 帰還・死亡・放棄の結果画面に、目立たないリンク「結果をシェア」を出す。ボス練習では出さない
- 画像: 1200×630 の結果カード。結果、到達区画とセクター、撃破数、倒したボス、構えていた武器（レアリティの色）、チップ（多い順に4つ、同じものは「×枚数」）
- 投稿文: `SECTOR/DIVE <到達区画> <セクター>から帰還した。<ボス>を撃破。#SectorDive` とゲームの URL
- タッチ端末で画像付きの共有ができるときは共有シートを開く
- PC では共有シートを使わない（Mac などの共有シートには X が出ない）。結果画面の中に、カードの画像と「画像をコピー」「画像を保存」「X で投稿」（投稿文入りの投稿画面）を出す。1回のクリックでコピーとタブを開くのを両方やると、コピーが失敗するので分けている
- 「画像をコピー」はクリップボードに画像を書けないブラウザでは出さない
- 倒したボスは `run.bosses` に記録し、中断データにも含める

## 10. 技術メモ

- 共通のコア: 描画・ループ・当たり判定・弾・音・入力・文言・セーブなどは リポジトリ直下の `engine/` を使う。開発とビルドはリポジトリの README「開発」。仕様は [engine/SPEC.md](../../engine/SPEC.md)。ここにはこのゲーム固有のことだけを書く
- 更新履歴: `updates.html`（公開ごとに1エントリ）。公開時にリポジトリ直下の `tools/build_updates.py` がコミットメッセージの `Changelog:` 行と `updates-archive.json` から生成する。拠点画面の設定タブとトップページのカードからリンク。書き方は README の「更新履歴のルール」
- アクセス解析のイベント（`track`、仕組みは engine/SPEC.md「アクセス解析」）。練習中は `stage_start` を送らない

  | イベント | いつ | パラメータ |
  |---|---|---|
  | `dive_start` | 出撃 | `start_depth`, `weapon`（装備1の武器）, `runs`（出撃回数） |
  | `dive_resume` | 中断からの再開 | `depth` |
  | `stage_start` | 区画・ボス部屋の開始 | `depth`, `area`（1〜3、4がボス部屋）, `sector`, `boss` |
  | `boss_defeated` | ボス撃破（練習を除く） | `boss`, `depth` |
  | `run_end` | 潜行の終わり | `result`（extract / dead / abandon）, `depth`, `area`, `sector`, `kills`, `bosses`, `chips`, `bits_kept` |
  | `practice_start` / `practice_end` | ボス練習の開始・終わり | `boss`, `depth`, 終わりは `result`（won / dead / abandon）と `seconds` |
  | `reboot` | 再起動 | `count` |
  | `share` | シェアの操作 | `method`（native / panel / copy / save / x） |

- 構成: `index.html`（HTML・CSS）＋ 入口の `main.ts` ＋ `js/` 以下のモジュール。`main.ts` が全部を読み込んだあと、言語・音量・拠点画面・システムの登録とループの開始（`boot`）を行う（決まりは engine/SPEC.md の「基本」）
- 多言語化: 画面に出る文言はすべて `js/lang/`（`ja` と `en`）に置く（仕組みは engine/SPEC.md の「文言」）。武器・チップ・セクターなどの名前と説明は `js/system/text.ts` が定義に流し込む。言語は設定タブで切り替え、`save.settings.lang` に保存する。英語のときは本文のフォントを Chakra Petch にする
- 文言を足したら `node tools/check_i18n.js games/sector-dive`（リポジトリ直下で）を実行する。コードと HTML で使っているキーが全言語にあるか、言語どうしでキーと定義の項目がそろっているかを照合する
- 確認用に `?lang=en` を付けると英語で開く
- 定義（数値・名前・種類の一覧）は `js/data/` に置き、ロジックのファイルには書かない。`js/data/` のファイルは読み込み時に他のファイルの関数を呼ばない

ゲームの js は関心ごとにフォルダを分けている: `data/`（定義）、`lang/`（文言）、`system/`（セーブ・計算式・言語データの流し込み）、`world/`（地形の生成と、生成まわり）、`actors/`（プレイヤー・敵・弾・ボスの振る舞い）、`flow/`（潜行の流れと画面、毎フレームのシステムの登録、BGM の切り替え）、`ui/`（HUD・入力の割り当て・シェア）、`dev/`（確認用フック）。

| ファイル | 中身 |
|----------|------|
| `../../engine/<フォルダ>/*.ts` | ゲームをまたいで使うコア。一覧は [engine/README.md](../../engine/README.md)、仕様は [engine/SPEC.md](../../engine/SPEC.md) |
| `js/data/*.ts` | **定義だけ**（ロジックを持たない）。`weapons`（武器・レアリティ・オプション・改造費）、`enemies`（敵と調整値）、`bosses`（ボスの体力・大きさ・攻撃パターンの数値 `tune`）、`viewmodels`（構えている銃の形）、`level`（壁・目線・台・遮蔽物の高さ）、`biomes`（セクター）、`progress`（区画数・`TUNE`・拠点強化・再起動）、`perks`（チップ）、`controls`（ボタン配置と操作一覧）、`sfx`（効果音のレシピ）、`music`（曲調） |

| `js/lang/<言語>.ts` | 文言。`ui`（画面の文言）と `data`（武器・チップ・セクターなどの名前と説明）。今は `ja`（基準）と `en` |
| `js/system/save.ts` | セーブの既定値、読み込みと旧版の変換、保存 |
| `js/system/rules.ts` | 定義を使う計算式（進行度、ドロップ、改造後の武器、売値） |
| `js/flow/music.ts` | どの場面でどの BGM の層を鳴らすか（再生は engine、曲のデータは `js/data/music.ts`） |
| `js/world/render.ts` | 弾などの共有ジオメトリ、床と壁のテクスチャ |
| `js/world/level.ts` | 地形の生成と描画、危険床、ゲート（当たり判定と経路は engine/world/tiles.ts） |
| `js/world/entities.ts` | 弾・拾い物の生成、敵の生成（敵オブジェクトの項目一覧もここ）。パーティクルは engine/render/fx.ts |
| `js/actors/player.ts` | プレイヤー、武器のレアリティ・+値・オプション、構えている銃のモデル、射撃、被弾、撃破 |
| `js/actors/bosses/common.ts` | ボスの共通処理（生成、体力倍率、撃破後の処理）、予告レーザー |
| `js/actors/bosses/<名前>.ts` | ボス1体ずつの生成と行動 |
| `js/ui/input.ts` | キーとボタンの割り当て（`INPUT`）、持ち替え・拾う・回復 |
| `js/ui/hud.ts` | HUD、ミニマップ、設定、タッチボタンの設定（`TOUCH_LAYOUT`）、言語の切り替え |

- プレイヤー側の調整値（HP、スタミナ、ダッシュ、回復キット、チップ率、死亡時のビット）は `js/data/progress.ts` の `TUNE` にまとめてある
- 描画: three.js r128（cdnjs）。3Dモデルや画像は使わず、図形とCanvasで作ったテクスチャだけで描く
- セーブ: localStorage の `sector-dive-v1`（読み書きは engine の `loadStore`）。1深度が4区画だった頃のセーブ（`stageV` なし）は、最深記録と中断データのステージ番号を3区画の数え方に変換する
- 開発用フック（URLの末尾に付ける）
  - `#smoke`: `tools/headless.sh 'games/sector-dive/#smoke' 200000` で流す。全セクターの区画と全ボスを一通り動かす。あわせて、段差から降りたときの詰まり、進行度、盾、ボス練習（セーブが変わらないこと）、中断→再開→破棄、データ消去を確かめ、各セクター25回ずつ生成して全部屋に行き来できるかを調べる。結果はコンソールに `SMOKE ...` で出る
  - `#view-KWLN` など: そのセクターの区画にすぐ入る（スクリーンショット確認用）
  - `#view-haz`: 光っている危険床の上に立った状態で始まる（銃が床より手前に描かれるかの確認用）。`#view-haz-smg` のように武器を指定できる。`#view-perk`: チップ選択画面を開く（`#view-perk4` で4枚）。`#view-share`（`-dead` で死亡時）: 結果カードの画像を表示、`#view-share-res`: その結果画面。`#tab-<sortie|up|practice|settings>`: 拠点のタブを開く。`#view-susp`: 中断データがある拠点画面（`-panel` で PC のシェア欄を開く）
  - `#view-pick`: 足元に武器を落とした状態で始まる（拾うときの表示の確認用）
  - `#boss-phantom` など: そのボスの練習にすぐ入る（ボス名は watcher / crusher / core / phantom / trinity / bastion）。`#boss-phantom-3` のように末尾に数字を付けると、その深度の強さになる
