# Sector Dive Extended 仕様書

複数階の建物を潜るローグライトFPS。Sector Dive を改造した実験作で、Sector Dive とは別のゲームとして置く。

- **この文書の読み方**: Sector Dive と違う所だけを書く。1章「Sector Dive と違う所」が、今動いている仕様。書いていないことは Sector Dive の仕様書（[games/sector-dive/SPEC.md](../sector-dive/SPEC.md)）と同じで、どの章が同じかは 2章の表にまとめた。まだ入れていないものと案は 3章
- **【未決】** は、まだ決めていないこと。**【案】** は、決定ではない案
- ゲームの名前は「Sector Dive Extended」、ID は `sector-dive-ex`。ID（フォルダ名）は変えない: 更新履歴はこのフォルダを触ったコミットから作るので、変えると過去の履歴が外れ、URL とセーブのキーも変わる
- 出発点は Sector Dive のコードの写し（`games/sector-dive/` → `games/sector-dive-ex/`）。写したあとは、Sector Dive の修正は自動では入らない。セーブは Sector Dive とは別のデータ

## 0. ひとことで言うと

| 項目 | Sector Dive | このゲーム |
|------|-------------|------------|
| 1深度の構造 | 区画3つ＋ボス区画。ゲートで次へ進む | 3〜5階の建物1つ。階段室とエレベーターで階を移り、順路の最後の最下階でボス部屋に入る |
| ボス | 専用の区画 | 最下階にあるボス部屋。入るとボス戦になる |
| ロックダウン | なし | 1つの建物に最大1回。部屋に閉じ込められ、敵が2回湧く。報酬はレアチップ1枚と武器 |
| 部屋を飛ばしたとき | ショートカット補給 | それに加えて、ボス部屋に入るときに、制圧していない部屋のぶんのチップを選べる |
| 移動 | 歩きとダッシュ | それに加えて、ダッシュを押し続けると走る |
| マップ | 2D | 2D と、建物全体の 3D |
| 見た目 | 色と線の模様でセクターを分ける | セクターごとの絵（壁・床・天井・ドア）と小物 |
| チップ・武器・敵・ボス・セクター | 15種・5種・11種・8体・6種 | チップ・武器は同じ（増やすのはこれから。3章）。ボスは Sector Dive の6体に HOIST と SURGEON を足した8体。敵は Sector Dive の9種に迫撃砲と修理ドローンを足した11種。セクターは8種（Sector Dive の6種に、ショッピングモールと閉鎖病院を足した） |
| 中断からの再開 | 区画の開始時点からやり直す | 同じ建物で、倒しきった部屋は空のまま、最後に移った階から再開する |

バランスは Sector Dive の数値を土台にする。敵のいる部屋の数を Sector Dive の1深度に合わせて、敵とボスの体力の伸びをそのまま使う。

## 1. Sector Dive と違う所（今の実装）

### 建物と階の移動

- **建物**: 階の数と、階ごとの部屋の数を決める（`ROOMS_BY_FLOORS`・`LAST_FLOOR_ROOMS`・`LAST_GAP` in src/world/building.ts）
  - 階の数: 3〜5階（建物ごとに乱数で決める）
  - 階の高さの差: 8m。最下階とその上の階の間だけ 14m（下の「ボス部屋の高さ」）
  - 最下階の部屋: ボス部屋とふつうの部屋3〜4つ
  - ほかの階の部屋の数: 3階ならセクターの元の数、4階なら4つ、5階なら3つ（平均で約13部屋、Sector Dive の区画3つは 13.6）
    - 敵のいる部屋の合計を、階の数によらず Sector Dive の1深度に近づけるため
- **順路**: 建物ごとに、階を回る順番（順路）を決める（`makeRoute` in src/world/building.ts）
  - 最上階から始まり、全部の階を1回ずつ通って、最下階（ボス部屋）で終わる
  - 1歩で動くのは3階ぶんまで（`LIFT_REACH`）
  - 3階の建物は 1→2→3 の1通り、4階は 1→2→3→4 と 1→3→2→4 の2通り、5階は間の3つの階をどの順でも回る6通り（1→2→3→4→5、1→2→4→3→5、1→3→2→4→5、1→3→4→2→5、1→4→2→3→5、1→4→3→2→5）から乱数で選ぶ
  - 順路の1歩ごとに、階段室かエレベーターが1つだけある（ほかの階どうしは直接つながらない）
  - 1階ぶんの移動は半々で階段室かエレベーター、2階ぶんの移動はエレベーター
- **階段室**: 隣り合う階をつなぐ
  - 形: 上下の階の同じ位置にある、7タイルの直線（下の階の入口、坂4つ、踊り場2つ）
  - 最下階へ下りる階段室: 間隔が 14m なので坂が7つの10タイル（坂1つで 2m 上がる）
  - 坂を歩いて上り下りする
  - 踊り場: 両方の階の床で、階段寄りのタイルに乗ると下の階、奥のタイルに乗ると上の階が「今いる階」になる。切り替わっても、プレイヤーの位置も見えている景色も変わらない
- **エレベーター**: 隣の階か、1つか2つ飛ばした階へ行く
  - 乗り場: 止まる階の同じ位置にある1タイルで、紫の床が目印
  - 動き出す条件: 床の中央（1.2m 以内）に 0.45秒立つと動き出し、1階ぶんにつき 2.2秒で着く
  - 階を飛ばすとき: 途中の階を壁に囲まれた昇降路で通り抜ける（その階には降りられない）
  - 乗っている間は歩けず、ダメージを受けない
  - 着いたあとは、一度降りて乗り直すまで動かない
  - ロックダウン中とボス戦中は動かない
- **ドア**: 左右に分かれて壁の中へ開く（`DOOR_CFG` in src/world/doors.ts）
  - 開ききると、扉は壁の面より 6cm 奥まで入る（天井とも 6cm 空ける）
    - 扉の端が壁の面と同じ位置に重なると、ちらつくため
  - 7m 手前から開き始め、約0.1秒で通れるようになる
  - 短い通路の両端にドアが並ぶときは、片方だけ残す（2タイル以内に並ぶドア。ボス部屋のドアは必ず残す。`thinDoorPairs` in src/world/building.ts）
  - 幅2の通路（旧市街ビル群・ショッピングモール）のドアは、並んだ2タイルで1枚のドア（幅 8m。扉は 4m ずつ左右の壁に入る。2タイルのうち、より開いているほうに合わせて動く。間引くときも2タイル一緒）
  - 階段室とエレベーターへの通路にはドアが無い。この通路は、ドアのすぐ横（ドアのタイルとその周り8タイル）を通らない（`tryBuilding` in src/world/building.ts）
    - 横を通ると、ドアを避けて回り込める道ができ、扉が通路に沿った向きで立ってしまうため
- **敵のいない部屋は作らない**: 開始部屋とボス部屋のほかは、どの部屋にも敵がいる。ロックダウンのある建物でも、ふつうの部屋は減らさない（ロックダウンのぶん、戦いが増える）
- **中庭**: 建物に、上下の階を見通せる中庭を1つ作る（`COURT_KINDS` in src/world/courtyard.ts。中庭の生成はこのファイルにまとめてある）
  - 場所が無い建物には無い。最下階には作らない（ボス部屋が1階ぶんより高いため）
  - 降りることも、階をまたいで撃つこともできない（穴は当たり判定の上では壁）
  - 種類: 下の2種類があり、どちらが出るかはセクターで決まる（`addCourt`）
    - 外壁に囲まれた中庭: 九龍城と廃墟街
    - 屋根つきの吹き抜け: 溶融炉区画・深層ノイズ・廃棄データ層
    - 通路に沿って長く伸びた吹き抜け（ガレリア）: ショッピングモール
    - 旧市街ビル群はどちらも出て、建物ごとに半々で決まる
  - 屋根つきの吹き抜け
    - 穴: 3×3 タイルの穴が階を貫く
    - 回廊: どの階にも周りに幅1タイルの回廊があり、いちばん下の階では穴の所も歩ける床
    - 穴の縁にガラスの手すり、いちばん上の天井に天窓、地面に光だまり
    - いちばん下の階の穴と回廊（5×5 タイル）は、その階の部屋の1つで、ほかの部屋と同じように敵がいて、制圧する部屋（ボス前の補給など）にも数える
    - 出入口はドアではないので、ロックダウンの部屋にはならない
    - 床から天窓まで通る物（廃棄データ層の配線の立ち上がり、溶融炉区画の熱い配管）は、回廊の外側の壁の角に立てる
      - 穴の上の宙に立てると、見上げ・見下ろしを縦に横切るため
  - 外壁に囲まれた中庭: 5×5 タイル（置ける階が1つしか減らないなら 7×7）の屋外の井戸
    - 四方は建物自身の外壁で、窓が1つおきの列に階ごとに並び、一部に明かりがつく
    - 床のある階では、外壁の窓と部屋側の窓は同じマスにある（旧市街ビル群と廃墟街。`WallSides.yard` in src/world/looks/common.ts、engine の `alongOpen`・`facadePicture`）
      - 中庭に面した外壁のマスは、列が奇数なら部屋側も外が見える窓、偶数なら窓なし
      - ベランダの端のマスのように、床から見える面のどれかが中庭と直角を向くマスも窓なし（その面の窓からは、中庭ではなく建物の中を見ることになる。`#bld-courtalong` で正面に見える）
    - 貫く階の上に2階ぶん、下に3階ぶん、壁だけの階を描く。上は夕方の空、下は舗装した地面
    - 貫く階ごとに、外壁の3タイルぶんがベランダになる
    - 外壁・空・地面は板に描いた絵で、当たり判定は無い（`buildYardShell` in src/world/courtMesh.ts）
  - 旧市街ビル群の中庭では、夕日が当たるのは西を向いた面（東側の外壁）だけで、残りの3面の窓は夕方の薄暗い空の絵になる
    - 中庭の外壁の窓は、ブラインドが下りた絵だけ
      - 半分上がった絵はブラインドの下に外の夕方の街が描いてあり、裏に部屋がある中庭の壁では、建物を突き抜けて外が見えるため
  - 廃墟街では、中庭の外壁と、窓から見える自分の建物の外観の割れ窓を、ガラスの奥が外の景色ではなく暗い部屋の絵にする（`Look.innerWalls`）
  - ベランダの形は階ごとに3つのどれか（`YARD_SHAPES`。建物ごとに始まりを決めて順に回すので、隣り合う階は同じ形にならない）
    - 見晴らし: 外壁の3タイルぶん。行き止まり
    - 渡り廊下: 中庭の1辺の全部。両端の角（つながる先が見つかった側だけ。少なくとも片方）から通路でその階につながる。片側が中庭に開いた、まっすぐの通路になる
    - 橋
      - 見晴らしから中庭の真ん中をまっすぐ渡り、向かいの見晴らしに着く。向かい側も通路でその階につながる（つながる先が無ければ橋は架けず、見晴らしだけにする）
      - 橋は幅1タイルで、屋根が無く、両側に手すり、下に床板と鉄の桁を描く
      - 橋のタイルはその階では床なので、歩けて、敵も渡る。ほかの階からは上や下に見える
      - 屋根つきの吹き抜けの橋も同じ作りで、床板の裏にその階の天井の絵を貼る（外壁の中庭の橋は、空の下なので暗い床板のまま）
        - 暗いままだと、下から見上げたときに黒い板に見えるため
    - 橋のある高さには、九龍城砦の中庭を横切る電線・提灯・看板を張らない
  - 屋根つきの吹き抜けの回廊には、入口のほかにもう1つ出入口を作る
    - まず向かい側で、つながる先が見つからなければ残りの2辺で探す
    - 2つ目の通路は、1つ目の通路に合流させない（すぐ輪になって戻るだけになるため）。通り抜けられる場所になる
    - 橋: 地面でない階では、出入口が向かい合っているとき 60% で、その2つを結ぶ橋を吹き抜けの真ん中に架ける（`ATRIUM_BRIDGE_CHANCE`）
    - 橋のある吹き抜けでは、吊り物（ランプ、クレーンのフック、ケーブル）を四隅に寄せ、橋を横切る高さのケーブルの棚は置かない
  - ガレリア（ショッピングモールの吹き抜け）
    - 穴: 幅3 × 長さ9タイルの長方形で、長さは z 方向にも x 方向にも取れる
    - 大きさ: 長さ9の四角（穴・回廊・壁で 7×13 タイル）が置けなければ長さ7、それも無ければ3×3 の吹き抜けにする（シード1〜100のモールの建物では、長さ9が 95、長さ7が 2、3×3 が 3）。縦と横の両方を探し、通せる階が多いほうに置く
    - 回廊: 穴のまわりに幅1タイル。いちばん下の階は穴も歩ける床で、穴と回廊が1つの部屋（敵もいる）
    - 出入口: 回廊の両端の壁のまんなかに1つずつと、見つかれば長い辺のまんなかに1つ（後の通路は先の通路に合流させない）
    - 橋: 上の階の 60%（`ATRIUM_BRIDGE_CHANCE`）で、穴の幅3を渡る短い向きに、長さのまんなか付近に架ける。階ごとに、まんなかとその前後に長さの 1/4 ずれた位置を順に使う（向かい側の出入口は要らない。両側の回廊は端でつながっている）
    - 天窓: かまぼこ形のガラスで、細い鉄の骨が1タイルおきに幅を渡り、長さに沿って7本の桁が通る。ガラスは淡く透け、後ろに天井の光る板がある。ガラスの縁は天井より 1.8m 下がっている（`addVault` in src/world/courtMesh.ts）
    - 手すりは3×3 の吹き抜けと同じで、長い辺に沿ってつながる
    - 垂れ幕: 天窓から長さに沿って 4.5m おきに1本、短い・長いが互い違いで、左右にもずらして吊る。橋の近く（橋から 6m 以内）では、橋の床の 2.4m 上までしか下ろさない
    - いちばん下の広場: 長さに沿って枯れた植物の植え込みを2〜3個（長さ9は3個）と、まんなかに水の抜けた噴水の縁を1つ置く。どれも絵だけで、当たり判定は無い（`dressGalleria` in src/world/yardProps.ts）
  - 置く場所は、中庭とその周り（回廊と壁、または壁）の四角が、貫く階の全部で壁になっている所。外壁に囲まれた中庭は空に開いているので、その上の階でも四角に床が無い所だけ（上の階の通路や部屋が中庭の上にかぶらない）。部屋や通路の作りは変えない。回廊とベランダは、通路でその階につながる
  - 中庭の近く（40m 以内）では、貫いているほかの階は中庭の四角だけを描く（階のメッシュを作るときに、その四角のぶんを別のグループに分ける。`buildFloorMeshes` の `courtGroup`）。ほかの階の敵は映らない

建物の生成（`makeBuilding` in src/world/building.ts。階段室とエレベーターの置き方・通路・順路・行けるかの確認・階の開口は engine の `world/stairwells.ts`）

- 階の数と順路を決め、階ごとに部屋と通路を作ったあと、順路の1歩ごとに階段室かエレベーターを置く。場所は、つなぐ階（エレベーターは通り抜ける階も）の全部で壁（周り1タイルも壁）になっている所から乱数で選ぶ
- 置く場所は、前の移動との間に部屋を挟む（`placeLink`・`roomsOnWay` in src/world/building.ts）
  - 着いたタイル（1つ目は開始部屋の中央）からの最短の道が、部屋を2つ以上通る所にする（開始部屋は数えない。その階の部屋が足りなければ、ある分だけ）
  - 満たさなければ置き直す。16回で決まらなければ1部屋でよしとし、24回目はそのまま置く
  - この決まりが無いと、着いてすぐ（部屋を通らないか、1つだけ通って）次の移動に着く組が半分あった。入れたあとは 8%（6セクター × 60棟）
- 置いたら、階段室の入口・踊り場の先・エレベーターから、いちばん近い床まで幅1の通路を引く。通路は、ボス部屋とその周り、ほかの階段室、ドア・坂・高台・瓦礫を通らない
- 作ったあと、開始部屋から全部の階の全部の床へ、階段室とエレベーターを使って歩いて行けることを確かめる。置く場所が無いときと、行けない床があるときは、決まった順で次のシードを試す（30回まで）

### 敵

- **敵の強さ**: 順路の順に強くなる（階の上下ではない）
  - 進行度: 順路の k 番目の階（0 から）で「深度 × 5 ＋ 4 × k ÷ 階の数」、ボスが「深度 × 5 ＋ 4」。3階の建物なら 0・1.33・2.67 で、Sector Dive の区画3つと同じ
  - 表示: 左上に「D1 2/4」のように、順路の何番目かと階の数を出す（`buildingStage`・`stageLabel` in src/core/stages.ts）
- **動く階**: 動かすのは今いる階だけ。ほかの階は地形とドアだけが描かれ、敵は出ていない
- **階段でついてくる敵**: 階段室で階を移ると、起きていて近くにいる敵がついてくる（`takeFollowers`・`updateFollowers` in src/world/level.ts）
  - ついてくる敵: 歩いて10タイル以内。動かない敵とボスは残る
  - 出てくる所: 移った先の階の、プレイヤーが階を移ったタイルに、そこまで歩くのにかかる時間のあとで出てくる（近い順に、0.6秒以上あけて1体ずつ）
  - 来る途中は場に居ない（描かれず、弾も当たらない）
  - エレベーターではついてこない
  - ついてきた敵の強さは、元の階のまま。数えるのも元の部屋で、移った先で倒して元の部屋の敵が居なくなれば、その部屋は制圧済みになり、報酬は倒した場所に出る（ロックダウンの部屋の敵を、ロックダウンの前に全部倒した場合は、制圧済みにせず報酬も出さない。その部屋は入るとロックダウンになる）
  - 敵が出てくる前にプレイヤーがまた階を移ると、来る途中だった敵は元の階に戻る（その階に残した敵と同じ扱い）
  - ついてきた敵を置いたままプレイヤーがその階を出ると、敵は元の階の自分の部屋へ戻る（部屋の中の空いたタイルに、眠った状態で。`sendStragglersHome` in src/world/level.ts）。すぐ後ろに居る敵は、戻らずについてくる。その階に残すと、元の部屋は敵が居ないのに制圧にならず、報酬も出ないため
- **階に戻ったとき**: 階を出るとき、その階の生きている敵と落ちている物（武器・チップ・回復キット・ビット）を、そのままの状態で取っておく（`stashFloor`・`restoreFloor` in src/world/level.ts）
  - 戻ると、出たときのまま元に戻る（傷ついた敵は傷ついたまま、追ってきていた敵は階段の途中にいる）
  - 弾と衝撃波は消える
  - 落ちている武器は、その階に初めて入ったときにだけ置く
  - 取っておくのはメモリの中だけ。中断から再開したときは、倒しきった部屋は空、敵が残っていた部屋は敵が全部戻り、落ちていた物は無くなる
- **動かない敵は押し返されない**: ショットガンとランチャーの爆風は、敵を 0.8m 押し返す（Sector Dive と同じ。`knockAway` in src/actors/combat.ts）
  - ただし動かない敵（砲台と、BASTION の砲台）は押されない
    - 床にボルトで留めた見張り銃なので
  - Sector Dive は押されて、BASTION の砲台が炉のまわりの持ち場からずれていた
- **連鎖爆破の威力**: 倒した敵の爆発で、まわりの敵にダメージを与える（`CHAIN_SHARE`・`chainBlast` in src/actors/combat.ts）
  - ダメージ: 倒した敵の最大体力の 30% × Lv（`CHAIN_SHARE` in src/actors/combat.ts）
  - 半径: Sector Dive と同じ 2.5＋0.5×Lv で、ただし 4.5m（Lv4）まで（`CHAIN_R_MAX` in src/actors/combat.ts）
    - 重ねるほど威力は上がるが、部屋ごと巻き込むほどには広がらない
  - 小さい敵が爆発しても、まわりの硬い敵は少ししか削れない。与ダメージ倍率は掛けない
  - ねらい: Sector Dive は 18×Lv×与ダメージ倍率×敵HPの伸びで、倒した敵の大きさを見ないので、火力のチップを積むと、小さい敵1体の爆発でまわりの硬い敵まで倒れていた
- **迫撃砲（mortar）**: 距離を取りながら（16m）、遮蔽物の裏や高台にいるプレイヤーの足もとへ山なりの弾を撃つ
  - 出る所: 旧市街ビル群とショッピングモールにだけ出る（砲台の代わり。`ELITE_TYPES` にも入る）
  - 数値: 体力 55、速さ 2.0、ビット 6、弾のダメージ 20（敵のダメージ倍率が掛かる）
  - 撃つ条件: 起きていて、プレイヤーとの距離が 24m 以内で、壁だけの見通しがあるとき（遮蔽物と高台はさえぎらない。`hasLOS` を高さ無しで呼ぶ）。約3.5秒おき（`MORTAR_INTERVAL` に `ENEMY_TUNE.fireInterval` と 0.8〜1.25 倍のばらつきが掛かる）
  - 弾: 撃った瞬間のプレイヤーの足もと（先読みはしない。着弾点の高さはその場所の床）を狙い、1.4秒かけて山なりに飛ぶ。頂点は撃った所と着弾点の高い方の 4m 上（天井の 0.3m 下まで）。途中では何にも当たらず、撃ち落とせない。迫撃砲が倒れても、飛んでいる弾は落ちる。着弾の瞬間に、半径 2.6m・床から高さ 1.5m 以内にいるプレイヤーにダメージ。敵には当たらない
  - 予告: 撃った瞬間から、着弾点の床に赤い輪（半径は爆発と同じ 2.6m）が出て、飛んでいる間に内側が満ちていき、着弾で消える。着弾で小さな爆発と音。階を移ると、飛んでいる弾は消える（`MORTAR_*` in src/actors/mortar.ts、撃つ判断は src/actors/enemies.ts）
- **修理ドローン（medic）**: 攻撃しない。プレイヤーから離れて飛び、近くでいちばん傷んだ敵をビームで直す
  - 出る所: 閉鎖病院と溶融炉区画に出る（`ELITE_TYPES` には入らない）
  - 数値: 体力 36、速さ 6.0、ビット 5、飛ぶ（高さ 2.1m）
  - 直す相手: 起きていて、同じ階で 12m 以内、壁だけの見通しがある敵のうち、いちばん傷んだもの（体力の減った割合に、盾が立っていれば盾の減った割合を足す）。ボスとほかの修理ドローンは直さない。0.5秒おきに選び直し、相手が直りきるか、倒れるか、12m より離れたら離す
  - 直す速さ: 1秒に、相手の最大体力の 20%。盾が立っていれば、盾も同じ割合で戻る（割れた盾は戻らない）
  - 動き: プレイヤーが 6m より近くて見えていると、プレイヤーから真っすぐ離れる。そうでなければ直す相手へ寄り（4m まで）、相手がいなければプレイヤーから 14m を保つ
  - 見た目: 直している間、ノズルから相手へ緑の線（ビーム）が出て、相手に緑の火花が散る。直す相手のほうを向く（`HEAL_*` などの数値は src/actors/medic.ts）

### プレイヤー

- **走る**: ダッシュを押したあと、押し続けて移動していると走る（`TUNE.sprintSpeed`・`TUNE.sprintCost`、`applySprint` in src/flow/update.ts）
  - 移動速度1.5倍、スタミナを毎秒12消費し、その間は回復しない。離す・止まる・スタミナが尽きる、のどれかで終わる。無敵は無い
  - 走りながら撃つと、どの武器も弾が大きくばらつく（ばらつき +0.05。ふだんブレない SMG・レールガンも同じ。`RUNNING_SPREAD` in src/actors/firing.ts）
  - スタミナが足りずダッシュが出なかったときも、押し続ければ残りのスタミナで走る
  - 操作
    - PC: ダッシュのキーを押し続ける
    - スマホ: ダッシュボタンを 0.25秒以上押し続けると、指を離しても走り続ける（狙うのに右手の指が要るため）。スティックを半分より手前に戻すと止まる。「スティック倒し切りでダッシュ」が on なら、倒し切ったままでも走る
- **プレイヤーの移動の刻み**: 1フレームの移動を 0.3m 以下の刻みに分けて、1刻みごとに足元の高さを上げながら進める（`MOVE_STEP`・`movePlayer` in src/flow/update.ts）
  - 1フレームが長いとき（およそ 25fps 以下）にダッシュで坂や階段を上ると、移動先が足元より 0.7m 以上高くなって壁と同じ扱いになり、坂の途中で止まっていたため
- **スタミナ回復の上限**: チップ「瞬発回路」で上げられるスタミナ回復は、毎秒102（基本の3倍）まで（`TUNE.staminaRegenCap`、`PERKS` の `sprint` in src/data/perks.ts）。届くと選択肢に出なくなる
  - 上限が無いと、十数枚でダッシュ1回ぶんが一瞬で戻り、無敵のダッシュを続けられた
  - Sector Dive には上限が無い

### ボス

- **ボス部屋のドア**: 赤く光り、上に「BOSS」と出るドア。開閉と、倒したあとのゲートを扱う（`BuildingState.beaten`、`resetFloorEvents` in src/flow/events.ts）
  - 流れ
    1. ドアの前（4m以内）で1.2秒待つと開く（操作して開ける形にはしない）
    2. 部屋に入るとドアが閉まる
    3. 1.2秒後にボスが出る
    4. 倒すとドアが開き、部屋に「前進」と「帰還」のゲートが出る
  - 倒したときに消えるもの: ボス部屋の中の敵（ボスが呼んだ敵など）と敵弾だけ。その階のほかの部屋の敵は残る
  - 倒したあとにほかの階へ行って戻ってきたとき
    - ボスはもう出ない
    - ボス部屋のドアは開いたまま
    - ゲート（節目なら強化ターミナルも）が同じ場所にまた立ち、段階はボスのものに戻る（前進のゲートで次の深度へ進むため）
  - 表示: 「BOSS」は、ドアの手前（両側 1.2m）に出す
- **ボス部屋の高さ**: ボス部屋だけ、天井の高さが 12m（ほかは 6m。`HALL_H` in src/data/level.ts）
  - 12m にするのは、ジャンプするボス（CRUSHER は体の中心が 6.6m まで上がる）が天井に埋まらないようにするため
  - HOIST のレールも、この天井の下に渡す
  - 最下階とその上の階の間隔は 14m（ボス部屋の 12m に、ほかの階と同じ床の厚さ 2m を足した高さ。`LAST_GAP` in src/world/building.ts）
    - ボス部屋は上の階の下に収まる。上の階の作りは変えていない（部屋を置けない場所を作らない）
    - 前は間隔が 8m で、ボス部屋の 6m より上が上の階の高さに立っていた
    - 両方を同時に描かないように、ボス部屋の中とドアの近く（14m 以内）では今いる階だけを描き、ボス部屋の上の部分は最下階にいる間だけ描いていた
    - 間隔を広げて、この描き分けはやめた（2026-10-22）
  - 階ごとの間隔は engine の `StairwellConfig.gaps`（engine/SPEC.md 4.5.1）
  - ふつうの部屋の天井は 6m のままで、最下階の天井から上の階の床までは 8m 空いている（見えない）
  - 階段室の天井の上とエレベーターの昇降路のまわりは、その階の上の間隔まで壁で埋める（`FloorPlan.above`）
  - 当たり判定は変えていない（見た目だけ）
  - ボス部屋には、天井の照明を置かない（九龍城・溶融炉区画・旧市街ビル群・廃墟街・廃棄データ層・ショッピングモール）。ふつうの高さ 6m に付けると、12m の天井の下で宙に浮くため
    - 深層ノイズは、12m の天井に付ける
- **ボスの子機**: ボスが呼ぶ子機は、ボス部屋の中に出る（`minionCount`・`arenaRoom` in src/actors/bosses/common.ts）
  - 子機の数の上限（NOISE CORE と PHANTOM と HOIST と SURGEON にある）は、ボス部屋の中にいる敵だけで数える
  - その階のほかの部屋に残っている敵は数えない
- **CRUSHER の攻撃**: Sector Dive の CRUSHER から、3つ変えた（ほかの5体の行動は同じ。`updCrusher` in src/actors/bosses/crusher.ts、数値は `BOSS_META.crusher.tune`）
  - 歩きながら撃つ
    - 攻撃の合間に歩いて近づく間、プレイヤーを狙った扇状の弾（3発、速さ 14m/s）を撃つ
    - 歩き始めて 0.5秒後に1回目、そのあとは 1.1秒ごと（体力が半分以下で 0.8秒ごと）
    - 合間は 1.0〜1.4秒なので、1回の合間に撃つのは1回（体力が半分以下で2回）
    - 走り（11.1m/s）より速いので、離れて走っていても届く
    - 衝撃波が広がっている間は撃たない（衝撃波と弾を同時に避けるには、ダッシュ2回では足りないため）
    - そのぶん、ジャンプの着地のあとの合間は、ほぼ撃ってこない
  - 2連続の突進（体力が半分以下）
    - 1回目の突進は、壁に当たっても時間切れになってもスタンせず、0.6秒で向き直ってもう一度突進する
    - スタン（1.6秒、被ダメージ1.5倍）と激突の衝撃波は、2回目の終わりにだけ出る
    - 体力が半分より多い間は、Sector Dive と同じく1回ごとにスタンする
  - 着地の2発目の衝撃波（体力が半分以下）
    - 広がる速さは 6m/s（Sector Dive は 9m/s。1発目は 12m/s のまま）
    - 出るのは Sector Dive と同じ着地の 0.45秒後
    - 遅くするのは、ボスに向かってダッシュで1発目を抜けると、近づいたぶん2発目が早く届き、無敵が切れた直後に当たっていたため
    - 12m 以上離れていれば、押し直す間（0.6秒以上）ができる
  - ねらい: 突進のたびにスタンし、攻撃の合間は歩くだけで、離れた相手への攻撃が追尾弾しか無かった。隙が多く、走りが入ってからは離れていれば安全だった
  - 第二段階に入る時
    - 体力が半分を切ったときに地面にいれば、その場で
    - ジャンプの途中なら、着地してから（`aloft` in src/actors/bosses/crusher.ts、`updateEnemy` in src/actors/enemies.ts）
      - 第二段階に入る演出の間、ボスは止まるので、宙に止まらないようにするため
    - 強くなった攻撃の数値は、半分を切った時点から効く
- **HOIST**: 搬入口の天井クレーン（`updHoist` in src/actors/bosses/hoist.ts、数値は `BOSS_META.hoist.tune`）
  - 体力: 基本 1500 に `bossDifficulty` の倍率
  - 見た目と当たり
    - ボス部屋の天井の下に、壁から壁へ2本のレールが渡り、その上を梁（ブリッジ）が動き、梁の上を台車が動く
    - 台車から吊るした磁石が撃つ所（中心が床から 4.8m、当たりの半径 1.9m）
    - レール・梁・台車は見た目だけで、撃っても効かない
    - 磁石の下には光だまり（ほかのボスにある、足元の色の光）は置かない。床の影の輪と見分けがつかなくなるため
  - 動き
    - 台車は、プレイヤーの頭上へ、x と z をそれぞれ秒速 6m で寄せる（真っすぐなら歩き 7.4m/s で離せる。斜めは 8.5m/s）
    - 部屋の壁から 4m の内側までしか動かない
    - 攻撃の合間は 2.6秒（体力が半分以下で 1.8秒）、最初の攻撃は登場の 1.6秒後
    - 攻撃は、荷を落とす、磁石で引き寄せる、荷を落とす、の順に回る
  - 撃つ
    - 台車がプレイヤーを追っている間と、荷を落としに寄る間、磁石の下の2丁の銃が撃つ
    - プレイヤーへ3発の扇（幅 0.18rad、秒速 15m、HOIST のダメージ）を 1.6秒おきに撃つ（体力が半分以下で5発、1.2秒おき）
    - 最初の扇は登場の 1.6秒後
  - 荷を落とす
    1. 台車がプレイヤーへ秒速 7m（各軸）で寄り、1m まで近づくか 1.3秒たつと止まる
    2. 止まった所で、磁石の下にコンテナかパレットの荷が出て、床に影の輪（黒い円、半径 2.2m。縁に黄色の細い輪）が出る。迫撃砲の予告は赤い輪、こちらは黒い影と黄色の縁
    3. 影は 1.2秒かけて濃くなり（最後の4分の1は縁が点滅する）、荷が落ちる（加速 35m/s²）
    4. 着地した瞬間に、輪の中にいたら、HOIST のダメージの 2.2倍（CRUSHER の突進と同じくらい）。ダッシュの無敵中は当たらない
    5. 荷は砕けて消える（破片と土煙、音、画面の揺れ）
  - 荷が砕けると、中から crawler が1体出る（落ちた所から 1.6m の周り。ボス部屋にいる子機が4体になるまで）
  - 磁石で引き寄せる
    1. 台車はその場で止まり、磁石が 0.7秒かけて青白く光る（うなる音）
    2. そのあと 2秒間、プレイヤーを磁石の真下へ、毎秒 9m で動かす（移動に足す。歩き 7.4m/s は負け、走り 11.1m/s は逆らえ、ダッシュ 24m/s は抜けられる）
    3. 引いている間は、磁石からプレイヤーへ向かう細い青い線と、床で磁石へ縮んでいく青い輪が出て、画面が少し揺れる
    4. 引き終わりに、磁石の真下へ荷が出て、影の予告と落下は「荷を落とす」と同じ
  - 第二段階（体力が半分以下）
    - 荷から出る crawler が2体になる（子機が4体までなので、少なく出ることがある）
    - 攻撃の間隔が 1.8秒になり、銃の扇が5発・1.2秒おきになる
    - 攻撃の途中（磁石が光ってから荷が落ちるまで）に体力が半分を切ったときは、攻撃が終わってから第二段階に入る（`aloft`）
  - 撃破: 磁石が落ちて床に転がり（土煙と音）、台車は止まった所に残る。荷と引き寄せの線は消える（`onDown` in src/data/types.ts、`hoistDown` in src/actors/bosses/hoist.ts）
- **SURGEON**: 手術室の天井から吊られた手術ロボ（`updSurgeon` in src/actors/bosses/surgeon.ts、数値は `BOSS_META.surgeon.tune`）
  - 体力: 基本 1500 に `bossDifficulty` の倍率
  - 体
    - 部屋の真ん中の、床から 7m の高さ（当たりの半径 1.8m）
    - 天井の柱に付いていて動かず、ゆっくりプレイヤーのほうを向く（毎秒 0.7rad）。柱は見た目だけ
    - ボスの体力の帯が減るのは、体に当てたときだけ
  - 腕: 体から腕が3本下がる
    - 腕はそれぞれ別の敵（`sarm` in src/data/enemies.ts。撃つと体力が減り、壊れると落ちる）で、先端が当たり（半径 1.0m）
    - 体力は体の 11%（`armHp`。体と同じ深度で）
    - 腕の位置はボスが毎フレーム決める（`anchored` in src/data/types.ts。ふつうの敵の移動と向きは付けない）
    - 腕は登場の演出のあとに、0.4秒かけて生える
    - 腕を撃ち落とすと、その腕の攻撃は止まる。落ちた腕は床に転がる
    - 体が倒れると、体と残っている腕が落ちる（柱は残る）
    - 腕は子機の数には数えない
  - 攻撃の順
    - 登場の 2.4秒後から、2.4秒ごと（体力が半分以下で 1.7秒）に、メス、針、鉗子の順に1本ずつ。壊れた腕は飛ばす
    - 腕が1本も無いときは、体が弾の輪（14発、秒速 8m）を同じ間隔で撃つ
    - 攻撃の途中に体力が半分を切ったときは、攻撃が終わってから第二段階に入る（`aloft`）
  - メス
    1. 床に細い赤い線が、体の下からプレイヤーの先まで引かれる（0.9秒。最初の 0.6秒はプレイヤーを追い、最後の 0.3秒は止まって点滅する）
    2. そのあと、線の左右どちらかの 35°（合わせて 70°）の端から、ビーム（明るい芯と赤い光）が床から 1.3m の高さを 0.8秒かけて反対の端まで回る
    3. 通ったときに1回だけ、SURGEON のダメージの 1.4倍。ダッシュの無敵中は当たらない
    - ビームは体の軸から 2m の所から、線と同じ長さ（プレイヤーの先 5m、14m 以上）。体の下（2m 以内）は当たらない
  - 針
    - 腕がプレイヤーのほうへ出て、0.5秒で狙いを定める
    - そのあと、5本の細い針（幅 0.09rad の扇、秒速 22m、SURGEON のダメージ、弾の大きさ 0.6）を撃つ。体力が半分以下で7本
  - 鉗子
    1. 床に薄い水色の輪（半径 2m）が出て、1.0秒かけて濃くなる（最後の4分の1は縁が点滅する）。輪は最初の 0.4秒だけプレイヤーを追う
    2. 腕は輪の上へ伸びて（遠いほど長くなる）、輪が濃くなりきったときに叩きつける
    3. 輪の中にいたら、SURGEON のダメージの 2倍。ダッシュの無敵中は当たらない
    4. 叩きつけたあと 0.4秒は降りたまま
  - 第二段階（体力が半分以下）
    - 壊れていた腕が、もとの体力で1回だけ生え直す（もう一度壊したら戻らない）
    - 修理ドローン（`medic`。ふつうの敵を直し、ボスは直さない）が2体、部屋の中に出る（腕を除いた子機が4体になるまで）
    - 腕を直されるので、先にドローンを撃つとよい
  - ヒント: 初めて会ったとき（とボス練習）に「腕を撃ち落とすと、その攻撃が止まる」と出る

### ロックダウンと中断

- **ロックダウン**: 部屋に閉じ込められ、湧く敵をしのぐと報酬が出る（src/flow/events.ts）
  - 起きる所: 1つの建物に最大1回。出入口が全部ドアの部屋が無い建物では起きない
  - 流れ
    1. 部屋に入りきると、ドアに鍵がかかって閉まる（`shutBehindPlayer`）
    2. ドアが全部閉まりきったら始まる（バナー・警報・BGM・湧き。`shutLockdown`）
    3. 部屋の敵（最初の敵）を倒しきると、その部屋の敵数ぶんが湧く。これが2回
    4. 湧いた敵も倒しきると終わり、報酬が部屋の中央に並んで出る（`endLockdown`）
  - 報酬: 選択肢が全部レアのチップ1枚と、★★以上の武器1つ。ふつうのチップをもう1枚出すと、強くなりすぎるため。湧いた敵もビットと回復キットを落とす
  - 表示と音
    - 閉まっている間は、画面のふちが赤く明滅し、上に「LOCKDOWN 1/3」と段階が出る（最初の敵が1、湧くたびに進む）
    - 始まりのバナーは赤。警報の音が、始まりと湧くときと 2.4秒ごとに鳴る
    - BGM は、そのセクターのボス戦のアレンジになる
  - 例外
    - 戸口に体がかかっている間は閉まらない（ボス部屋も同じ）。ドアは人が立っていると閉まらないので、入ってすぐ引き返すと部屋の外に取り残されるため
    - 起きている敵が戸口に立っていると、どいて閉まるまで始まらない。開いたままでは閉じ込められていないため。待つ間に外へ出たら鍵が外れ、また入ると閉まる
    - ロックダウン中とボス戦中に部屋の外へ出たときは、ドアの鍵が外れ、中へ戻るとまた閉まる（`shutOnlyWithPlayerIn`）。外に取り残されると、部屋は開かずエレベーターも動かないため。鍵のかかったドアも、起きている敵が戸口に立っている間は閉まらないので、そこから外へ出られる
    - ドアが閉まったとき部屋の外にいるその部屋の敵（プレイヤーを追って出た敵、階段でほかの階へついて行った敵）は、部屋の敵に数えない。外に締め出された敵は中で倒せず、部屋が片付かなくなるため。どの部屋の敵でもない敵として、その場に残る。ロックダウン中に一度外へ出て戻ったときも同じ（`releaseStrays`）
- **中断からの再開**: 最後に階を切り替えた時点から再開する（`packSeen`・`unpackSeen` in src/world/building.ts。チェックポイントに入れる）
  - 建物は同じシードから作り直し、倒しきった部屋は空のまま
  - マップも、その時点までに見た所が開いた状態で戻る（全部の階ぶん）
  - 階段で来た階なら階段の上（踊り場）、エレベーターで来た階ならその床の上から始まる
- **建物の作りの版**: チェックポイントは、建物の作りの版（`BUILDING_V` in src/world/building.ts）を持つ
  - 建物の作り方が変わって同じシードから別の建物ができるときは、版を上げる
  - 版の違う潜行を再開すると、今の作りの建物に合わせて組み直す（`fitBuildingState`）
    - 順路の同じ番目の階の、そこへ来る階段かエレベーターの上から始まる（最初の階なら出撃地点）
    - 順路でそれより前の階は済んだ扱い（どの部屋も敵がおらず、武器の箱も出ない。ロックダウンがその階なら済み）。チップの取り直しにならないようにするため。その階から先は、まだ入っていない扱い
    - マップは全部の階で未探索に戻る。チップ・武器・体力・ビットはそのまま
    - 決まったシードの建物の形を、テストが覚えている。作りが変わるとそのテストが落ちるので、版を上げてから覚えさせ直す

### 武器の数値

|---|---|---|
| ハンドガン | 28 | 約80 |
| SMG | 8 | 約80 |

### マップと表示

- **階の表示と案内**: 左上の表示は「D1 2/4 3F　九龍城」の形で、順路の何番目か・建物の何階か（最上階が 1F）・セクターを出す。階を移ったときのバナーにも階を出す（`floorLabel` in src/core/stages.ts）
  - マップでは、順路の先へ進む階段室・エレベーターを、種類の色（階段は緑、エレベーターは紫）に点を重ねて出す。来た道のほうは灰色にする。全体マップでは「▼ 先へ」「▲ 戻る」と添える（`markers` in src/ui/minimap.ts）
  - どちらも、そのタイルを見るまではマップに出ない（探すのは探索のうち）。マップが開くのは、自分のまわり（半径約4タイル）のうち、立っているタイルから見通しが通るタイルだけ。壁の向こうは開かない（隣の階段室や、鍵のかかったドアの奥が、見つける前に写らないようにする）。部屋に入ると、その部屋の全体と出入口は Sector Dive と同じく一度に開く（`reveal` in src/world/level.ts）。
  - ボス部屋のドアだけは、通路から見たときにマップに出る（ミニマップ、全体マップ、3D のマップ）。出るのは、向いている方向から左右 0.6 ラジアン以内にあり、霧の中で敵が見分けられる距離より近く、ドアのすぐ外の通路まで見通しが通るとき。閉まったドアのタイルは見通しの上では壁なので、まわりが開く仕組みだけでは、部屋に入るまで出ない（`sightHallDoor` in src/world/level.ts）
  - 敵は、見たことのあるタイルにいれば、寝ていても起きていても出る（`markers` in src/ui/minimap.ts）。部屋は入った時点で全体が開くので、柱の陰や段差の向こうで寝ている敵も出る。部屋の外からは見通しが通るタイルしか開かないので、入る前に部屋の中の数がわかることはない
- **マップ**: 今いる階の 2D のマップと、建物全体の 3D のマップ（3D は `updateMap3D` in src/ui/map3d.ts。描くのは engine/src/ui/floormap3d.ts）
  - 2D のマップは、階段室とエレベーターの位置に、行き先の向き（▼ 下の階へ、▲ 上の階へ）を出す（階段は緑、エレベーターは紫。小さいマップにも出す）
  - 全体マップには2つのページがある: 今いる階の 2D のマップと、建物全体の 3D のマップ
  - 3D のマップは、見たことのあるタイルを階ごとの板として重ね、階段室（緑の坂）とエレベーター（紫の柱）で結び、自分を矢印、見つけたボス部屋のドアを赤い印（床から浮いて、ゆっくり膨らんで縮む）で出す
    - 高さのある空間は箱で出す（`volumesOf` in src/ui/map3d.ts）
      - 中庭・吹き抜けは、貫いている階のいちばん下の床からいちばん上の階の床までの、薄い灰色の箱（面はごく薄く、辺も控えめ。行き先ではないので目立たせない）。穴そのものは床ではなく見たことにならないので、貫いている階のどれかで、穴かそのまわり1タイルを見たときに出る
      - ボス部屋は、階の間隔の 0.85 倍の高さの赤い箱で、部屋に入ると出る（`HALL_BOX`。3D のマップは階を等しい間隔で描くので、最下階の上の間隔が広いことは描かない。実際の天井は 12m で、階の間隔 8m に対して 1.5 倍あり、そのまま描くと箱が上の階のタイルを突き抜けるので、上の階の手前で止める）
  - 3D のマップには、どの階にも建物の外周の線と階の名前（1F が最上階）を出す。まだ見ていない階にも出る。今いる階から離れた階ほど薄くなる
  - 3D のマップの大きさは、2D のマップと同じ高さで、横は画面に合わせて広げる（左右に 220px ずつ空けて最大 1000px。ミニマップと右側のボタンにはかぶらない。縦長の画面では 2D と同じ正方形）
  - PC: M キーで 2D のマップを開閉する。N キー（操作「立体マップ」。キー設定で変えられる）で 3D のページを開き、もう一度押すと 2D に戻る。3D のページを開いている間は、マウスのロックを外してカーソルを出す。ドラッグか移動キー（左右で回す、前後で傾ける）で地図を回し、プレイヤーは動かない。ホイールで拡大・縮小、右ボタンのドラッグで見る場所を動かす。閉じるとロックを取り直す
  - スマホ: ミニマップか地図をタップするたびに「閉じる → 2D → 3D → 閉じる」。3D のページは、1本指のドラッグで回し、2本指で拡大・縮小（指を開く・閉じる）と見る場所の移動（そろえて動かす）
  - 3D のページを開いている間は、ゲームが止まる（敵も弾も時計も動かない。PC もスマホも同じ。2D のマップを開いている間は止まらない）。ループのモードを `map` にして、潜行のシステムを動かさない（`LOOP.mode` in src/flow/update.ts）。地図の下の案内にも「一時停止中」と出す
  - 地図の下に、今できる操作を1行で出す
  - 3D のマップは毎フレーム描く（2D のマップとミニマップは間引いて描く。3D は回している間の動きがなめらかに見えるように）
- **フレーム数**: スマホ（タッチ端末）は 1秒に 60フレームまで（`TOUCH_MAX_FPS` in src/flow/update.ts、engine の `LOOP.maxFps`）
  - 120Hz の画面では1つおきに描く。120 のままだと、重い場所で 60〜100 に落ちたときに戦闘の手ざわりが変わったため
  - `?fps120` を付けると制限を外す。PC は画面のまま
- **描画**: 建物全体を重ねて持ち、各階に天井がある。描画の負荷を抑えるため、描くのは今その場で見える所だけにする（`showNeighbourFloors` in src/world/level.ts）
  - 階: 今いる階と、階段室の近く（40m 以内。霧の見える距離のほうが短ければそちら）にいるときの、その行き先の階。エレベーターでつながる階（行き先と途中の階）は、乗っている間だけ（シャフトは壁で囲まれていて、乗り場からはほかの階が見えない）
  - 区画: 階の物のうち、三角形の多い種類（1つの階で 3000 以上）は、8×8 タイルの区画に分けて作る（engine の `chunkInstances`。少ない種類は、区画に分けると描く回数が増えるだけなので、階まるごとのまま）
    - 毎フレーム、画面に入っていて霧の終わりより近い区画だけを描く（`cullChunks`）

### 見た目

  - 部屋ごとの壁（`Look.roomWalls`、`wallPic` in src/world/looks/common.ts）: 部屋に種類を持たせるセクターが使う。部屋の種類は `Look.roomKinds`（階を描くときに部屋の番号ごとに求め、`wallKinds` に置く。-1 は種類なし）。壁のマスに接する床のマスの部屋（複数なら番号の小さいほう）の種類で絵の組を選ぶ: 通路に面していない壁は、約8割5分がその種類の絵、残りが地の壁。通路に面した壁は、その種類の店先。種類のない部屋の壁は共通の壁。部屋に接しない壁（通路だけに接する壁）は、`laneWalls` を含めて今までの振り分け。`wallSides` の決まりが先に効く

  - エレベーターの壁（`Look.liftWalls`、`wallPic` in src/world/looks/common.ts）: エレベーターのマス（`building.ts` が階ごとに `wallLinks` に置く）に接する壁の絵。1枚目が壁の面、2枚目があれば、入口から見て決まった側の壁（ボタンの盤）。指定の無いセクターは変わらない

  - crawler: 体当たりする車。2つの車輪（タイヤ、黒いリム、ハブ、外側の横棒）の間に、低い車体と一段上がった甲板、くさび形の鼻先。前に、歯が3本ついた衝角の棒を2本の油圧の腕で突き出す。後ろに、車体を水平に保つ小さな補助輪と支柱、排気管2本、放熱板、アンテナ。走っている間、車輪が転がる。mini はその小さいもの（数が出るので、衝角の腕・放熱板・アンテナを省く）
  - drone: 上から撃ってくる、4つの回転翼のドローン。胴の上に電池、4本の腕の先にモーターと回転翼。鼻先に黒い枠のカメラ、腹の下に銃（機関部・銃身・弾倉）、着陸用のそり、アンテナ。翼は回り続ける
  - turret（と、ボスが呼ぶ bturret）: 床にボルトで留めた見張り銃。4本のボルトの台座、配線の這う柱、旋回の輪。その上の頭は、銃を載せる箱、前の黒い防盾、冷却筒つきの2連の銃身、左右の軸、後ろの弾薬箱、上に放熱板とランプ、アンテナ。眠っている間は、頭が左右を見回す
  - brute: 押して撃つ、履帯の突撃車。履帯の前後に歯車と遊動輪。車体の前は斜めの装甲板で、その前に、鉄の刃先のついた排土板を2本の油圧の腕で構える。砲塔にバイザー、両肩に2連の発射筒の箱。後ろに排気筒2本と黒い格子、アンテナ
  - sniper: 距離を取る長い銃。小さな車輪のついた3本の油圧の脚、光る帯を巻いた柱、油圧の腕で傾ける頭。銃は、銃身・握りの筒・先の制退器。上に照準器と赤く光るレンズ、後ろにつり合いの電池、アンテナ
  - mortar: 遮蔽物の向こうへ弾を投げる砲。四隅をボルトで留めた低い台座、帯を巻いた箱の胴、斜め前に傾けた太い筒（足もとに光る帯、口に黒い輪）。筒は左右の受けと軸で支え、2本の支柱で台に突っ張る。後ろに砲弾を立てた弾薬箱、アンテナ。体は暗い赤褐色。撃つ弾は迫撃砲弾の形（暗いオリーブの胴、鋼の弾頭と信管、尾の筒に4枚の羽、尾で燃える装薬）で、飛ぶ向きに弾頭を向ける（`mortarRound` in src/world/models/ebulletLooks.ts。`?plain` では光る玉）
  - medic: 敵を直して回る修理ドローン。丸い胴に光る帯、上に蓋とランプ。脇と後ろに3つの囲いつきのファン（回る）。腹から前へ折れた腕の先に、光る先端のノズル（ビームはここから出る。`MEDIC_NOZZLE`）。後ろに部品箱、アンテナ。体と光は緑
  - shield: 盾を押しつけてくる機械。2本の短い履帯と車輪、旋回台の上に胴、1本のスリットの頭。両肩から油圧の腕2本と横棒で、自分の背丈ほどの盾（鉄に黒と黄の帯とのぞき窓）を前に構える。撃つべき背中には、動力の箱、排気筒2本、放熱板、アンテナ。盾が割れると盾だけが外れる（腕と横棒は残る）
  - bomber: 飛んでくる機雷。面で角ばった殻に、光る帯とそれを挟む黒い輪、まわりに長い触角（信管）8本、上に信管の蓋と橙のランプと撃針。下に、浮くための噴射口。殻と触角は回りながら来る（噴射口は回らない）
  - splitter: 割れて mini を2体出す運び屋。面で角ばった殻が、光る縦の割れ目を3つの留め金で閉じている。両脇に mini の車輪を黒い留め具で抱える。前に黒い枠の1本のスリット、下に噴射口、後ろに排気管2本、アンテナ
  - trooper: 関節のある人型の兵士（`buildHumanoid` in src/world/models.ts、装甲は `dressTrooper`）
    - 関節の位置と動きはそのままで、素の見た目の箱は使わず、関節に骨組みと装甲を付ける。箱を積んだ人形でなく、ほかの敵と同じ組み立てた機械に見せるため
    - 骨組みは、鉄の球の関節（肩・ひじ・股・ひざ）と暗い色の手足、細い腰（背骨の筒と輪）、胸の両脇から肩の球へ渡る肩の受けと軸、ひざ下の油圧の筒
    - 装甲は、胸と傾けた胸板（下に光る帯）、ベルト、襟、背中の装置（排気筒2本、光る帯）、多面体のヘルメット（光る目、ひさし、あご当て、とさか、耳の無線機とアンテナ）、斜めの肩当て、前腕の覆い、ももの板、傾けたひざ当て、すねの覆い、足
    - 銃は機関部・弾倉・覆い・銃身。どれも関節についていくので、歩きと構えに合わせて動く
  - 地面にいる敵は、眠っている間、じっとしている（Sector Dive は全部の敵が上下に揺れる）。飛ぶ敵（drone・medic・bomber・splitter）は Sector Dive と同じく揺れる
  - ボスも機械として描く（`src/world/models/bossLooks.ts`）。暗い装甲に、パネルの継ぎ目・通気口・型番の刷り文字の絵（`bossHullMat` in src/world/models/machine.ts）。光るのは、ボスの色の細い帯・スリット・レンズだけ。どう浮くか、何で撃つか、どこで見るか、熱をどこへ逃がすかが形でわかるように、部品を付ける。足元の床には、ボスの色の大きな光だまり（浮いたり跳んだりしても、真下の床に出る）。大きさ、当たり判定、動き、攻撃は、光る立体のボスと同じ
    - WATCHER: 浮かぶ監視機。8角の胴の前に、ひさしの付いた大きなカメラ（黒いガラスの奥にマゼンタのレンズ）。両脇に浮上用の噴射口、後ろに推進の噴射口。腹の下に、12の銃口が並ぶ輪（弾の輪を撃つ所）。レンズの下に2連の銃。上にセンサーの箱、走査用の板、アンテナ3本
    - PHANTOM: 飛ぶレール銃。細長い胴と、下へ細くなる竜骨。弾の出る高さに銃が胴を貫く（2本のレール、その間の光、留め具3つ、後ろに尾栓、横に弾倉）。銃の上に照準器とマゼンタのレンズ。両脇に放熱板（下に浮上用の噴射口）。竜骨にワープ用のコイル
    - CRUSHER: 体当たりをする攻城機。段になった低い車体と、斜めの前面装甲。油圧の腕で前に突き出した、歯の付いた衝角。4本の脚（油圧）と、その横の跳躍用の噴射口。両肩に6連のロケット発射機。後ろに排気筒2本と放熱板。上の小さな塔に、光る細いスリット
    - TRINITY: 回りながら飛ぶ砲台が3機。どの向きから見ても同じ形。6角の胴に、銃3門と、その間に体当たり用の刃3枚。上にぐるりと光るスリットの付いた塔とアンテナ、下に浮上用の噴射口。帯とスリットは機体ごとの色
    - NOISE CORE: 部屋の中央に浮く炉。中で回るのは回転体（面で角ばった核、はずみ車、その上の発振部3つ、鉄の輪）。核は継ぎ目が紫に光り、両極が白く光る。まわりの枠は回らない: 放熱板の付いた柱3本（下に浮上用の噴射口）、上下の軸受けへ伸びる油圧の腕、輪2本（上の輪に光る線）、下の軸受けの下にレーザーの発振部
    - HOIST: 搬入口の天井クレーン。ボス部屋の壁から壁へ渡る錆びた鉄のレール2本、その上を動く梁（黄と黒の縞の帯、両端にレールを走る台車と黄色の灯）、梁の下の台車（巻き取りの胴と、ワイヤー）。ワイヤーの先は、重い箱型の磁石（錆びた鉄の車体に黄と黒の縞の帯、上に鎖で吊るしたフックの台、下に荷を支える黒い板と、青く光るコイルの面。板の下の向かい合う2つの角に、斜め下へ向いた2連の銃身の銃）。荷は、青緑のコンテナか、木のパレットの木箱の積み荷。天井の無いボス練習の部屋では、レールの端の下に柱が立つ
    - SURGEON: 手術室の天井から吊られた手術ロボ（`surgeonLooks.ts`。見た目だけで、当たりと大きさは変えない）。白と淡い緑のエナメルが汚れた塗装（ボスの色の薄い光を含む。ほかのボスの暗い装甲とは違う。継ぎ目の汚れ・錆の筋・灰色のしみ・欠け・ネジ・刷り込みの文字）。光だまりは置かない
      - 体: 黒い芯を6枚のエナメルの板が覆い、下半分は灰色の下殻。ぐるりと光の帯（12の灯）、ネジの列、背中に通気の板（ルーバー・ファン・排気管2本）、横に感知器のポッド2つ（アンテナと灯）
        - 前が顔で、バイザーの枠に、プレイヤーを目で追う大きなレンズ（左右 0.5rad・上下 0.5rad まで。ボスの色の虹彩）、小さなカメラ2つ、眉、測距の赤い点、状態灯5つ。顔の下に「OR-3」の札
        - 下に無影灯（皿に灯が12個と、真ん中に握り）。灯は普段は白く、攻撃のあいだはその色になる（メスは赤、針は緑、鉗子は水色）
        - 腕の付け根は3つの関節の箱で（前から 60° ずらして、レンズが2本の腕の間に見える）、腹から付け根へ管が這う
      - 吊り具: 体の首は、旋回環（歯付き）で、天井の吊り具に回って付いている（体と一緒に回るのは首の環まで）。吊り具は黒と黄の縞の襟、2段の太い柱、継ぎ目の環、配線の束（5本）と管の留め具、天井の板（黒と黄の縞の枠、ボルト）、板の下のレール2本と台車、斜めの支え4本、制御箱（「OR-3」の札と3つの灯）。体が倒れても吊り具は残る
      - 腕: 2本のリンクと、その間の肘の関節（左右に光る輪）。リンクは筒の箱（エナメルの輪、鋼の環、ラムの座の板）から、2段の軸が滑り出る（遠くへ伸びるときは軸が出る）。ラムと配線が沿う。手首の光る帯（ボスの色）は残してあり、光る帯のおかげで、腕は体と別の的に見える
      - 道具: メスは箱型の柄（通気口と赤い窓）・鍔・長い刃で、刃の縁と先の発振部が赤く、予告から薄く、ビームの間は白く熱くなる（先の光の輪も）。針は箱型の本体の上に薬液の瓶3本（淡い緑）と、6本の銃身の回転する弾倉で、撃つ前に回転が速くなり、撃った直後に銃口が光る。鉗子は蝶番の箱と、太い2つの顎（内側に歯の列）で、顎ごとにラムが付き、輪が濃くなるあいだは開き、叩きつけると閉じる
      - 撃ったもの: メスのビームは、白い芯と赤い光と、その外の薄い光の3層（赤い光は少し揺れる）で、床には光の帯が落ち（予告の線の下にも薄く）、ビームの下で床から火花が散る。刃の先から、ビームの出る所へ細い光が下りる。針は細くて先の尖った針に見える（`dressEBullet` の `needle`。当たりの大きさは変えない）。鉗子の輪は、薄い水色の面、縁の細い線、内側の細い輪、中から広がる明るい面（濃くなる速さを示す）、外へ脈打つ縁。叩きつけると、土煙・火花・閃光と、広がる輪が出る
      - 倒れたとき: 体は 1.1秒、火花を散らして垂れ下がり（0.4m）、灯がちらついて消えてから、床へ落ちる（レンズは下を向く）。腕も、短くぶら下がって火花を散らし、回りながら落ちる
    - BASTION: 炉を囲む要塞。8角の2段の台座。4つの面に2連の銃と放熱板、その間の4つの面に控え壁。控え壁から炉の上へ傾く爪（先に発振部、油圧の支え、排気筒）。炉は、鉄の輪2本と蓋付きの口が付いた、面で角ばった球で、爪の間で回る。シールドの球が全体を覆う
- **拾い物の見た目**: 床に落ちている物を、その物として描く（`pickupLook` in src/world/models/itemLooks.ts）。浮いて、上下に揺れて、回るのは Sector Dive と同じ
  - 武器: その銃そのもの（手に持つ銃と同じ形。2.1倍の大きさで横向き）。銃の真ん中のすぐ下に、レアリティの色の短い光る板。その下の床に同じ色の光だまり（★ は灰、★★ は青、★★★ は琥珀）。レアリティが上がるほど少し大きい
  - 回復キット: 緑の十字の入った白い救急ケース。緑の光る帯と光だまり
  - チップ: 回路基板。中央と縁が琥珀色に光る。基板だけが回りながら傾き、光だまりは水平のまま
  - ビット: 暗い縁の、琥珀色に光る六角のコイン。数が多いので光だまりは付けない
  - 拾える距離や中身は変えていない
- **弾と発砲の光、ゲートの見た目**
  - 弾: ハンドガン・SMG・ショットガンの弾は、白っぽく光る短い曳光弾（武器の色ではなく、どれも同じ色。`TRACER_HOT` in src/world/entities.ts）
    - レールガンの弾は、Sector Dive と同じ武器の色の長い光。ランチャーの弾は鉄色のロケット
    - 敵の弾も曳光弾にする: 進む向きに伸びた白い芯を、弾の色の光が包む（色は、べた塗りではなく、透けて重なる光）。弾の真下の床には、弾の色の小さな光だまりを出す（位置と高さがつかめるように）
    - 敵の弾の色・大きさ・当たり判定・速さ・飛び方は変えていない（`dressEBullet` in src/world/models/ebulletLooks.ts）
  - 発砲の光: 銃口から出る炎の形（Sector Dive は白い球。銃身を横切る星形と、前へ伸びる舌。`flashPaint` in src/world/models/gunLooks.ts）
  - 粒（着弾・撃破・爆発で飛び散るもの）: その色に光る小さな尖ったかけら（火花）にする（Sector Dive は色のついた小さな立方体）。上へ昇る粒（煙）は、透ける灰色。飛び方は変えていない（`useSparkLooks` in src/world/models/sparkLooks.ts。engine の `FX.partMat` を使う）
  - 衝撃波（CRUSHER など）: 床を走る炎の前線。床ぎわが白く、上へ向かって衝撃波の色の光が薄れて消える（Sector Dive は、色のついた平たい帯）。大きさ、速さ、当たり方は変えていない（`waveFront` in src/world/entities.ts）
  - NOISE CORE の回転レーザー: 色の光（透けて重なる）に、撃ち始めてからは白い芯が通る。予告の間は芯が無い。太さ、回り方、当たり方は変えていない
  - ゲート（前進・帰還）: 鉄の柱2本と梁の枠を、鉄の円い板の上に立てる。柱の足元は黒と黄の帯。柱のランプと梁の下の帯が、ゲートの色（前進は琥珀、帰還は水色）に光る。枠の中の輪と膜は Sector Dive と同じ役目（使えるようになると明るくなって回る）。使える距離や決まりは変えていない（`gateFrame` in src/world/portals.ts）

### コードの場所と道具

定義場所:

- 建物の生成は `makeBuilding`（src/world/building.ts。中庭はその中から src/world/courtyard.ts）
- 階の出入りは `startStage`・`crossToFloor`（src/flow/run.ts）
- 建物全体の描画と今いる階の切り替えは `showBuilding`・`enterFloor`（src/world/level.ts）と `buildFloorMeshes`（src/world/levelMesh.ts）
- 階段室・エレベーター・ロックダウン・ボス部屋の動きは src/flow/events.ts
- 建物の状態は `run.bld`（`BuildingState` in src/data/types.ts）で、チェックポイントに入る

- **ボット**: 自動で遊ぶプレイヤー（バランスを見るための道具で、公開版には入らない。`src/dev/bot.ts`）
  - 開発サーバーで `#bot`（または `#bot-<型>`）を開くと、ボットが潜行を遊ぶのを画面つきで眺められる（左下に今していることが出る。`?seed=<n>` で同じ建物になる）
  - 画面なしで何本も回して表にするのは `npm run sim`
  - ボットは人と同じ入力で動き、プレイヤーの型は6つ（初心者・探索型・速攻型に、それぞれ自動射撃あり・なし）
  - 使い方、型の中身、表の読み方は [sim/README.md](sim/README.md)

## 2. Sector Dive の仕様書の章との対応

章の番号は Sector Dive の仕様書のもの。「同じ」は、その章の内容をそのまま使う。

| 章 | このゲームでは |
|----|----------------|
| 1. ゲームの流れ | 1深度が建物1つになる（1章の「建物」「順路」）。ボスを倒すとボス部屋に「前進」と「帰還」のゲートが出る。ゲートの決まり、ロスト、セクターの順番のシャッフルは同じ |
| 2. 操作 | 同じ。足したのは、走る（1章の「走る」）と、3D のマップの操作（1章の「マップ」） |
| 3. プレイヤー | 同じ。足したのは、走ることと、移動の刻み（1章） |
| 4. 武器 | 5種、レアリティ・+値・オプションは同じ。威力などは1章の「武器の数値」。走りながら撃つとばらつく（1章の「走る」） |
| 5. チップ | 種類と出方は同じ（ボスから1枚）。部屋の敵を全滅させたときにチップが出る確率は 30%（Sector Dive は 50%。部屋が多いぶん、枚数が増えすぎるため。`TUNE.chipChance`）。足したのは、ロックダウンの報酬とボス前の補給（1章） |

## 3. まだ入れていないもの

方針は決まっていて、まだ作っていないもの。中身が決まっていないものは【未決】。

- **ほかの階の敵の続き**: 追ってきた敵が階段でついてくる所までは入れた（1章の「階段でついてくる敵」）。残りは次の2つで、入れるかは遊んでから決める
  - ほかの階に置いてきた敵を描く（今は、今いる階の敵しか描かない。階段の上から下を見ても、置いてきた敵は見えない）
  - 来る途中の敵が、階段を歩いて上り下りする様子を見せる（今は、階を移った瞬間に消えて、少しあとに踊り場に出てくる）
  - 【未決】エレベーターを敵が使うか（【案】使わない。階段だけ）
- **種類を増やす**: セクターとボスを3つずつ、チップと敵を数種。武器は5種のまま
  - 【未決】セクターのテーマ、ギミック、主な敵、ボス候補。【案】複数階が生きるテーマ（縦に長い塔、吹き抜けのある施設、地下へ降りていく坑道、階層のある廃工場）。外の市街地や森も、今の仕組みで作れそう
  - 【未決】足すチップ。【案】新しい要素に絡むもの（自分が敵より高い所にいると与ダメージが上がる、など）
  - チップを足すときの決まり
    - 同じ種類は足し算で重なる形にする
    - 別枠の掛け算になる効果は、入れる前に試算する（Sector Dive の分裂弾は、別枠の倍率になって上限を付けることになった）
    - 与ダメージに効く種類を増やすと、種類をまたいだ掛け算で深い潜行の伸びが大きくなるので、増やしたら難易度の伸びを試算し直す
  - 【未決】足す敵とボスの行動。【案】高い所から撃つ敵を、高台や塔の上に置く
- **見た目の続き**: 画面（HUD・チップ選択など）、拠点の順に、セクターの絵に合わせる
  - 【未決】画面のどこをどう変えるか
  - 画面の文字が明るい壁に重なると読みにくい所がある（廃棄データ層）。画面を調整するときに直す
- **はしごで上がる高台や塔**: 【未決】入れるか。はしごでしか上がれない場所は、近接の敵が来られず安全地帯になる
- **ドアの開く音**: 【未決】入れるか。ドアは 7m 手前から開くので、鳴る回数が多い

### 入れないと決めたもの

- **順路に入らない階**（通らなくてもいい階）。全部の階を1回ずつ通る
- **ロックダウン専用のチップ**。重ねられないと頭打ちが早く、上限なしだとバランスが崩れるので、ふつうのチップと武器を報酬にした（いまは、選択肢が全部レアのチップ1枚と武器）
- **ロックダウンの予告と、2回以上のロックダウン**。入るまで分からず、建物に最大1回
- **ボス部屋のドアを操作して開ける形**。前で待つと開く
- **エレベーターでしか行けない部屋**。階と階をつなぐのは、順路の1歩ごとに1つの階段室かエレベーターだけ
- **防具、属性、武器の種類の追加**
