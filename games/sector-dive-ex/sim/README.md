# ボットによる試行（Sector Dive Extended）

バランスを、人が遊ばずに見るための道具。ボット（自動で遊ぶプレイヤー）に潜行を何本も遊ばせて、結果を表にする。
公開版には入らない（ボットは `src/dev/bot.ts`、開発サーバーとこの試行だけが読む）。

## 使い方

```sh
CHROME="/path/to/chrome" npm run sim                                   # 全部の型 × シード 1〜10
SIM_SEEDS=1-20 SIM_STYLE=beginner,rusher npm run sim                   # 型とシードを選ぶ
```

- `SIM_SEEDS`: 建物のシード。`1-20` か `3,7,9` の形（既定は `1-10`）
- `SIM_STYLE`: プレイヤーの型。コンマ区切りで複数、`all` で全部（既定は `all`）
- Chromium の中で、画面を描かずにゲームのループを手で進める。実時間の数百倍で回る（1本あたり数秒〜数十秒。深く潜る型ほど長い）
- テストではない。`npm test` にも CI にも入らない

画面つきで眺めるときは、開発サーバー（`npm run dev`）で `#bot`（rusher）か `#bot-<型>` を開く。左下に、今していることが出る。`?seed=<n>` で同じ建物になる。開発サーバーではふだんのセーブで遊ぶので、自動射撃の設定はボットの型に合わせて書き換わる。

## 出てくるもの（`sim-results/`。コミットしない）

- `sector-dive-ex-summary.tsv`: 型ごとに1行。型どうしや、変更の前後を比べるのに使う
- `sector-dive-ex-<型>.tsv`: 1潜行ごとに1行
- `traces/sector-dive-ex-<型>-<シード>.trace.txt`: その潜行でボットがしたことの記録（秒・階・していること）。途中で止まる、時間がかかりすぎる、といったときに読む

### 集計の列

| 列 | 意味 |
|---|---|
| `depthMean`・`depthMedian`・`depthMax` | 到達した深度（1 = 最初の深度） |
| `bossesMean` | 倒したボスの数の平均 |
| `minutesMean` | 1潜行の長さの平均（ゲーム内の時間） |
| `died`・`gaveUp` | 倒れた本数、上限（ゲーム内90分）まで終わらなかった本数 |
| `diedAtDepth1` | 深度1で倒れた本数 |
| `killedBy` | 倒れたとき戦っていた相手の上位 |

### 1潜行ごとの列

| 列 | 意味 |
|---|---|
| `end` | `died`（倒れた）・`extract`（帰還）・`gave up`（上限まで終わらなかった） |
| `seconds` | 潜行の長さ（ゲーム内の秒） |
| `depth`・`bosses` | 到達した深度と、倒したボス（順に） |
| `toBoss`・`bossHp` | 最初のボスが出るまでの秒と、最後に戦ったボスの残り体力 |
| `weapons`・`chips`・`kills` | 終わったときの武器（名前とレア度）、取ったチップの数、倒した敵の数 |
| `damage`・`minHp`・`kits` | 受けたダメージの合計、体力がいちばん減ったときの割合、使った回復キット |
| `hazard`・`dashes`・`picked` | 有効な危険床の上にいた秒、回避のダッシュの回数、拾った武器の数 |
| `stuck`・`last` | 詰まってうろついた回数、最後にしていたこと |

## ボットの作り

- 人と同じ入力で動く（スティック、視線、射撃、ダッシュ、回復、武器の持ち替え）。当たり判定や体力には触らない
- 知っていること: 順路（階段とエレベーター）、ボス部屋、ゲート、マップに出る敵とボスの位置。歩いて届かない所の物は目指さない
- すること
  - 順路を進み、見えた敵に照準を寄せて戦う（距離を保って横に動く。撃っても相手の体力が減らなければ詰める）
  - ボスの取り巻きを先に撃つ
  - ボスごとの戦い方を知っている（初心者の型は知らない。下の表）
  - 当たりそうな弾は横へ、衝撃波は輪をくぐる向きにダッシュする
  - 危険床は遠回りできるなら避け、有効・予告中の床には踏み込まない
  - チップ・回復キット・武器を取りに行く。武器は、持っている弱いほうより1.1倍以上強ければ持ち替える
  - 回復キットは、回復量が無駄にならないときに使う（体力が2割を切ったら無駄でも使う）
  - チップは最初の候補を取る。ボスを倒したら次の深度へ進む
- 条件をそろえるため、潜行ごとにセーブを初期状態に戻し、乱数（建物、セクターの順、チップの候補、ドロップ）をシードで固定する。同じシードなら、遊び方が分かれる所までは同じ潜行になる

### 型（`BOT_STYLES`）

| 型 | 照準 | 回避 | 危険床 | 回復 | 進み方 | 拾い物 |
|---|---|---|---|---|---|---|
| `beginner`（初心者） | 遅く、ずれが大きい | 弾の15%にだけ反応 | 気にしない | 体力3割から | 順路を進む | 5m 以内 |
| `explorer`（中級・探索型） | 速く正確 | 弾の80%に反応 | 避ける | 体力5割から | 階の敵を全部倒してから下りる | 40m 以内 |
| `rusher`（中級・速攻型） | 速く正確 | 弾の80%に反応 | 避ける | 体力5割から | 順路を進む | 12m 以内 |

初心者はボスごとの戦い方を知らず、どのボスもふつうの敵と同じように戦う。探索型と速攻型は知っている。

それぞれに、自動射撃を切った型がある（`beginner-manual` など。照準が合ったときに自分で引き金を引く）。合わせて6つ。
型を足す・変えるときは、`src/dev/bot.ts` の `KINDS` の数値を書く。

### ボスごとの戦い方（`BOSS_PLAYS`）

何度か戦った人が知っていそうな範囲だけを持たせてある。弾と衝撃波の回避は、どの敵にも共通の動き。

| ボス | すること |
|---|---|
| CRUSHER | 10〜20m 離れて戦う。突進の線上にいたら横へダッシュする。壁でスタンしたら 4〜9m まで詰めて撃つ |
| NOISE CORE | 回転レーザーが 2.4m まで迫ったら、回転と逆向きにダッシュしてくぐる |
| PHANTOM | 柱の裏へ消えたら、ダッシュで追う（回避1回ぶんのスタミナは残す）。レーザーの照準が止まったら（発射の0.3秒前）、横へダッシュする |
| TRINITY | 体当たりの狙いが自分の近くなら、その場から横へダッシュする |
| BASTION | 砲台を先に壊す（取り巻きを先に撃つ動きで足りる） |
| WATCHER | 特になし（弾の回避だけ） |

## 読み方の注意

- ボットは人ではない。「迷う」「見てから避けにくい」といった感覚は拾えない。**数字そのものより、型どうしの差や、変更の前後の差を見る**
- ボットの腕の分が数字に入っている。ボス戦は、上の表の動きしか知らない
- 武器の持ち替えは、敵1体への秒間ダメージだけで比べている。ランチャーの爆風（まとめて当たる分）やレールガンの遠距離の強さは数えていないので、この2つは拾われにくい
- ボスが出るまでの待ち時間など、ページのタイマーで動く所は実時間で待つ。そこでは同じシードでも数フレームずれることがある
- 型の数値は、まだ実際のプレイの記録（アクセス解析）と突き合わせていない

## バランスを変える作業での使い方

1. 変える前に `npm run sim` を流し、`sim-results/sector-dive-ex-summary.tsv` を控える（別の名前で写しておく）
2. 変更を入れる
3. 同じシードで流し直し、型ごとの差を見る。狙った型だけが動いたか、ほかの型が巻き添えになっていないかを確かめる
4. 気になる潜行は、行動の記録（`traces/`）か、`#bot-<型>` と `?seed=<n>` で画面を見て確かめる
